# AI短片导演工作体系 V1.1｜Higgsfield 方法融合规范

日期：2026-10-26（北京时间）  
适用：《年复一年》《另一个家的布布》以及后续采用相同协作机制的短片  
状态：**工作方法已按用户本轮要求纳入；任何具体镜头、机位、动作、灯光及生成资产仍以各项目原有审批为准。**

## 0. 与原体系的关系

本规范是对既有“整段导演设计→空间/人物调度及动态预演→素材任务与审查→Seedance 2.5/H3 独立转译→草稿测试→导演验收→剪辑归档”的补强，**不是重建工作流，不覆盖旧审批，不要求重新安装软件或改换平台**。

- 用户：最终导演和创作审批者；已确认决定持续有效。
- ChatGPT：整段叙事与演技设计、镜头语言、光影、首尾帧任务、视觉验收。
- Codex：空间/机位技术核验、资产/版本/任务台账、双模型执行转译、样片问题定位与归档；建议不能代替导演审批。
- 既有 [《年复一年》协作工作流](../projects/年复一年/协作工作流与分工.md)、[导演审批规则](../projects/年复一年/导演决策与审批规则.md) 与 [Seedance V0.2 阶段草案](../projects/年复一年/seedance-2.5-prompt-standard-v0.2-draft.md) 继续有效；《另一个家的布布》沿用其项目已批剧本、空间规则、PLAN-003及预演资料。
- 仓库已有 [Higgsfield Acting](../skills/higgsfield-acting/SKILL.md) 和 [Production Pipeline](../skills/higgsfield-pipeline/SKILL.md) 的精简副本，可作导演参考，但其缺失的上游依赖、平台专属能力和未经实测结论不能当作本地可用功能。与既有导演批准冲突时，以用户批准和本规范边界为准。

## 1. 空间调度：同一坐标体系，不凭图像猜房间

### 1.1 空间“真值”与参考职责

每场开始时建立或读取一份**空间真值表**，逐项指明“来源、版本、是否已批、还缺什么”。不能混用：

| 信息 | 权威依据与用途 | 不得推定 |
|---|---|---|
| 房间实际尺寸/墙、柱、开口 | 实测或CAD原始房屋尺寸；读取不清时标“待量测” | 彩平图的绘制比例就是实测尺寸 |
| 家具与猫用品最终布置 | 本项目用户批准的家具布置母版及资产登记 | CAD原图中的旧家具仍是最终摆放 |
| 人物/猫路线和交汇边界 | 已批动线图、对应坐标说明；保留各世界可见性规则 | 2D路线获批等于3D无遮挡、视频可拍 |
| 角色/服装/道具身份 | 独立身份照、服装照和道具母版，各管各的 | 将服装参考的脸或环境背景当身份/空间真值 |
| 摄影机看到的画面 | 由上述尺寸与站位推得的摄影机预演及经审核帧 | AI单张“视角图”能反证其自身几何正确 |

若最新用户决定与旧文件冲突，记录差异、更新时间和审批来源；**不得静默重排家具、镜像空间或迁移人物站位**。

### 1.2 空间调度卡（每场/每个复杂镜头必填）

1. 固定统一的平面坐标原点、X/Y方向、单位（米）；禁止在不同视图重新定义左右前后。CAD尺寸与最终家具布置分层保存。
2. 记墙线、门洞、窗户、家具外轮廓、转角、不可进入区域；通道净宽与人物/抱猫占用宽度没有证据时写“未核”，不填想象数字。
3. 人物/猫以代号绑定起点、终点、面朝方向、脚点及动作路线（例如A0→A1、E→G、G→X）；区分时间顺序与平面箭头长度。
4. 摄影机用Cxx标机身位置(X,Y,Z)、朝向/俯仰、镜头类型或等效视角、画幅、焦距候选、对焦对象、视线轴线；若运动，还需起止位置、路径、速度/停顿和遮挡。
5. 同一白模至少导出**俯视定位图＋真实摄影机视图**；必要时加侧视/人物视线图。对比尺寸、近大远小、门框同向消失、遮挡、对切轴线、脚位与行动可达性。
6. 拟改变机位时，先在固定白模里移动“相机”，再生成相应参考帧；禁止通过单张AI改图凭空发明镜头另一侧。

**空间审核关口（置于旧阶段2内）：** 只有2D坐标、3D/透视可见性和人体动作包络三种证据都已检查，才能把该机位标记“空间预演通过”。如果只完成2D，须写“2D已批、3D未核”；用户不必对看不见的摄影机效果做盲目决定，应先展示预演图。

## 2. 演技设计：目标/阻碍/策略驱动，而不是情绪形容词

对主要角色建立**跨场角色表演母档**（体态、步态、重心、说话节奏、声音身份、典型视线习惯），按场景重新设计具体行为，不整段机械复制。每个表演镜头填写：

- **即时目标**：人物此刻具体想让谁做什么、想确认/隐藏什么。
- **阻碍与潜台词**：真实困难是什么；嘴上说的话与心里想的是否不同。
- **策略/动作**：伸手、整理东西、移动、避开目光、等待或停下手头动作等可以看见的行为。
- **感知与反应**：先听/看到了什么，再发生视线、头部、身体动作；反应不必与对白同步爆发。
- **身体物理**：脚点、承重、手部接触顺序、身体重心、呼吸、与道具/他人的距离；猫的动作符合体型和主动性。
- **眼神任务**：眼睛此时在寻找、确认、回避或判断什么；微表情必须与景别相称，远景不可依赖不可见的毛孔级表情。
- **表演节拍**：通常用2–4个有意义的变化描述一场小表演；允许克制长停顿，不为凑节拍强加动作。标出关键状态及可变的持续时长。
- **声音身份**：使用角色锁定的声线/音色基准；可用真人临时录音辅助情绪，但“Video Element音频驱动”等功能须以当前平台实测为准，不能视为通用能力。

**演技审核关口（仍属旧阶段2/B）：** 先答“角色为什么行动、动作给观众什么信息”，再确定如何拍；不允许只写“震惊、伤心、微笑”三个标签。前一镜的呼吸、手中物、情绪与位置要能进入下一镜。

## 3. 提示词工程：一个导演真源，两个模型独立执行稿

### 3.1 三层文件职责

| 层级 | 内容 | 谁作最终判断 |
|---|---|---|
| **导演真源（DIRECTOR）** | 戏剧目的、剧本版本、空间真值、表演节拍、镜头/运镜、光源、声音、接口、批准状态 | 用户审批创作选择 |
| **素材绑定与镜头验证（BLOCKING/ASSET）** | CAD/白模坐标、参考图唯一职责、实际图片SHA/版本、首尾状态、机位预演与验收证据 | 技术和视觉分开验收 |
| **模型执行稿（SEEDANCE25 / H3）** | 依导演真源编译的可复制提示词、实际工作流设置、真实平台参考编号、已知风险 | 样片检验模型执行，不反向改写已批创作 |

任一层更改应标记影响范围。Seedance/H3之间不得直接全文互抄，不允许由模型/Skill默认参数覆盖用户指定时长、画幅、声音、首尾帧或固定机位。

### 3.2 Seedance 2.5 执行稿（结构按镜头需要裁剪）

按“全局视觉风格→剧情/场景→角色和各参考职责→LOCATION空间硬约束→FIRST FRAME & BLOCKING→镜头/动作节拍→OPTICS/CAMERA→表演与物理→LIGHTING→AUDIO→禁止偏差→剪辑接口”顺序编译。原生单镜头须明确**single continuous take, no cuts**（或对应中文规则），不得在同一段又要求多个独立景别硬切；多镜头任务须明确每个Shot及其切点。

场景图是**几何/外观参考**，人物动线图是**调度数据**，电影首帧是**当前景别/构图**；不同透视的参考图不能不加区分地统称“首帧”。参考媒体平台编号未核对时统一写“待绑定”，严禁虚构@图号。480P草稿用于检查走位、运镜和剧情；若平台支持同任务ID升级才可沿原草稿升级1080P，否则重新高清生成仍须复验。

### 3.3 MiniMax H3 执行稿

保留相同导演目标，压缩到**少数可观察的动作与因果顺序**；将首尾帧/身份/场景/动作参考的真实接线关系另列。重点锁定位置、道具、双手分工、物理接触、视线变化、相机是否固定；复杂动作可分阶段写，但**不擅自缩短用户已指定的整段时长或拆镜**。若8GB显存/节点限制导致不可实现，提供诊断证据和替代方案供用户决定。

## 4. 一镜一卡的最小交付模板

每个镜头交付时按如下栏目记录（未知填“待核”，未批准填“待导演确认”）：

1. 镜头ID、所属场次、剧本版本、目标时长范围、叙事目的与观众信息变化。
2. 依据：正式平面/CAD尺寸、最终家具母版、角色/道具/场景文件的编号、SHA或链接、批准状态。
3. 场景与世界规则：空间边界/物件可见性、光源和时间；不可改变项。
4. 调度：角色/猫的起止脚点、朝向、行走路线、身体重心与接触事件。
5. 摄影机：Cxx坐标/高度/朝向/焦距候选/景别，固定理由或起止运镜轨迹，画面内可见/遮挡清单。
6. 表演：目标→阻碍→行为策略→感知→视线/呼吸/动作节拍；对白原文与潜台词。
7. 动态分解：初始状态、中间可验证状态、最终状态、动作不可回退项、首尾帧/剪辑接口。
8. 声音与光影：每个实际光源方向、明暗层次、色温连续性；环境音、台词、音画切入点。
9. 模型：独立Seedance/H3执行稿、真实引用绑定、唯一参数表、草稿任务ID/到期时间（若适用）。
10. 验收结果：空间、身份、动作、演技、相机、光影、声音、剪辑连续性；证据链接、缺陷归因、用户审批记录。

不为普通静态镜头制造无用字段：没有真实测得的高度/距离须标未知，不用看似精确的虚构数字填表。

## 5. 失败诊断：只修失败变量，不丢掉已通过成果

| 发现 | 首先核对 | 不应立即做 |
|---|---|---|
| 门框近远颠倒、家具换位置 | CAD/白模机位、消失方向、模型参考分工 | 在错误场景上叠加更长提示词 |
| 人物站错/穿过家具 | 2D路径、3D净宽/脚点、首帧站位 | 静默挪家具或更改已批路线 |
| 看不懂动作/道具自动移动 | 起始状态、手物接触、状态时间线、首尾帧与连接 | 只添加“真实物理”形容词 |
| 演技僵、眼睛无任务 | 目标/阻碍、反应节拍、视线/呼吸与声音素材 | 直接加“强烈悲伤/惊恐” |
| 光影漂移 | 实际光源、首尾帧/中间帧一致性、模型曝光变化 | 每轮随机更换电影灯光风格 |
| 视频切接后不连续 | 前镜尾状态、后镜首状态、物体/站位/声音/轴线 | 仅凭两个片段都好看就定稿 |

每轮记录：**现象→证据时间点/截图→原因类别（导演设计/空间源数据/参考素材/提示词转译/模型生成/剪辑）→仅修改变量→复测结果**。保留失败片段与有效片段，不把模型失误直接归咎于用户已批导演设计。

## 6. 两个项目的立即落地位置（不改变当前批准范围）

### 《另一个家的布布》

- 当前主问题是C61/K06-O0的3D空间与镜位，而非增加更多文字：CAD原始尺寸、用户批准的V2.2家具布置和PLAN-003二维动线**分别负责尺寸/家具/路线**。正在制作的3D白模应输出同一坐标下的俯视与C61相机视图，核A沙发餐厨端头G内站位、B在G外通道、人物包络与遮挡。
- 已采用的C61 v09空景仅是**停止局部门透视返修的工作候选**，不标记为几何精确标定；此前错误的O0人像候选不因本规范获得批准。
- SC04–SC06跨界镜头须保持G/E/X、A/B世界可见性、雷雨/23:00–23:30窗口、猫体型/毛感及“先感知后反应”的因果；镜头表现遵从已批剧情。
- SC06妻子“想留下又决定放手”的表演，可按“想确认→试图抓住→意识另一个自己也爱猫→放手”的目标/策略层次设计，但**具体表情、时长、剪辑方案仍待导演审批**。

### 《年复一年》

- 保留现有整段导演设计与用户明确批准的镜头衔接、旧盒遮挡及道具物理规则，不自动批准其余待审镜头。
- 优先将“手挪布→盒子显露→视线停顿”和“丈夫由入口入画”转换成动作接触/相机轴线/演技节拍卡；通过中间状态验证，避免盒子自行移动、妻子提前怀旧或场景跳变。
- 老年夫妻声音母档、自然表演、落地灯与台灯的有根据光线以及胶片质感是连续性约束，不靠随机增加噪点/柔焦掩盖AI皮肤和光学错误。

## 7. 生效与审批边界

用户本轮明确要求将Higgsfield的空间调度、演技设计、提示词工程融入现有导演工作体系，故本规范作为**跨项目方法入口**生效。**生效的是检查方法与交付结构，不是任何未审的具体导演决策。**

正式镜头生成仍遵循现有审批：剧本/段落目的→空间/人物/机位预演→素材与首尾帧实图验收→Seedance/H3草稿验证→用户审片及剪辑确认。不能把“已写提示词”“Skill已安装”“技术渲染成功”记成导演批准。

# SC04–SC07 完整镜头设计（人话调度，待导演核对）

2026-11-10。只做镜头设计，没有写提示词、没有建节点、没有生成。
依据：剧本 V1.6.7、《全片分镜脚本 现行总表》、导演已定做法，以及这几天读的案例和看的 5 条成片。
设计前调用了 `shot-recipes`（选配方卡）和 `seedance-shot-design`（核对时长与连续性规则）。

**怎么读这份稿**
- 每个镜头先写"观众这一刻要明白什么"，再写画面和动作。
- 动作用厘米、毫米、秒写，不写情绪词。
- "借自"一栏写明学的是哪个案例；标"看过"的是看过成片验证的，标"只读"的没验证。
- "做法"一栏：**生成**＝要花积分；**后期**＝剪辑里做，不花积分；**已有**＝已采用或已做好的素材。
- 积分按之前的经验估（约 9 积分/秒），只是估算。

**每场有两张表**
- 第一张"内容表"：观众要明白什么、动作、声音、做法、借自。
- 第二张"镜头语言表"：**景别、机位与角度、运镜、从上一镜怎么切过来**。表后有景别走势、运动分配和切换规律的说明。
- 切换用语：硬切＝直接切；动作切＝切在动作半途，下一镜接着这个动作；视线切＝先拍人看，再切到看到的；声音先入＝下一镜的声音先出来，画面后切；声音切＝切点落在一个声音上；匹配切＝两镜构图相同、内容替换。

**这次用上的五条学习结论（全场通用）**
1. 她的反应写在身体和手电上，少写脸。（来源：「幕Scene」手电走廊，看过）
2. 每条生成里，各镜秒数加起来等于总时长。（来源：《聊斋》独白那条，看过）
3. 凡是"若隐若现"的东西都走后期，不交给模型。（两个画布都验证了）
4. 长台词可以一个镜头撑到底，但要写清情绪台阶。（《聊斋》17 秒独白，看过）
5. 每场结尾留一个静止或拉远的停顿。（《聊斋》场尾，部分看过）

# SC04 窗边的影子（第八夜 22:58–23:15）

**这场戏观众要经历的**：等 → 落空 → 她自己迈进去 → 看见不该有的东西 → 不信 → 确认 → 认出是谁的东西 → 它出现 → 它走进来变成真的 → 她唤它，它回头。
**骨架**：沿用你 11-09 点头的 14 镜，不增不减。我改的是每镜里"她怎么反应"和"怎么分组生成"。

**一个贯穿全场的新设计：手电光束当她的表情**
她从镜头 1 起手里就拿着开着手电的手机。之后她每次受到冲击，先动的是光束，不是脸：光束垂下去、抖一下、停在地上不动。这样脸可以一直保持平静，解决"受惊过头"。

# SC05 真的抱到了（23:16–23:23）

**这场戏观众要经历的**：它在她眼前真的碰到了家具 → 她看见痕迹是怎么来的（前几夜的谜底）→ 坐垫是温的 → 它闻她、蹭她 → 她抱到了。

# SC07 它过得挺好的（第九天清晨）

**这场戏观众要经历的**：雨停了 → 旧照片 → 她照常收拾 → 手停在那道褶皱上，这次是她自己不抚平 → 丈夫说了句家常 → 她说它过得挺好 → 那边，它真的过得挺好。
**设计重点**：这场是全片的回声。三个镜头直接回扣前面：开场窗（片头）、褶皱（SC01）、同一张沙发（B 世界）。回扣镜头保持固定机位；其他镜头各给一个很小的运动，不再全固定。

**景别走势**：全 → 全 → 特 → 中 → 特 → 近 → 双人近 → 特 → 近 → 特 → 特 → 中。开头两个全景把人放进晨光里；中段特写和近景交替；最后从特写退到中景再渐黑。
**运动分配**：三个回扣镜头（1 接片头、5 接 SC01、10→11 接 B 世界）机位固定或只有 3 厘米的推；其余每镜一个小运动（推、横移、后拉），没有一镜是完全没理由的固定。
**切换的规律**：全场只有一次叠化（1→2）、一次定格（3）、一次匹配切（10→11）、一次渐黑；其余都是硬切。

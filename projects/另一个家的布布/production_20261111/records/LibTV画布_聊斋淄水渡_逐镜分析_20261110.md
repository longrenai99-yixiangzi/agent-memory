## 一、整套提示词的骨架（全片统一）

每条提示词 = **固定块 + 逐个 CUT**。这是我见过最规整的中文写法。

**固定块（每条开头整段粘贴）：**
1. 摄影固定（16mm 胶片、Cooke 复古镜头、自然光、不做舞台光）
2. 美术固定（宋代审美、色调清单、不出现现代元素）
3. 天气固定（暴雨戏专门有一段"暴雨天气强化"：近景看雨线、中景看雨幕、远景看雾）
4. 皮肤固定（人类 / 婴儿 / 鬼身各一段）
5. 表演总基调（如"这场戏不是惊吓，而是告别"）
6. 负面固定
7. 参考图绑定（一图一职责；音色也绑：`♪音频 9 是水鬼音色参考`）
8. 空间位置锁定（谁始终在哪，水流方向，岸与水的相对方向不能反转）
9. **连续性专条**（见第三节）

**每个 CUT 的固定字段：**
`时长 / 景别 / 角度 / 运动 / 焦段 / 位置锁定 / 画面 / 表演 Performance / Dialogue / SFX / 连续性 / 负面控制`

- 为什么这么写：固定块保证全场统一；CUT 字段让每镜"只表现一个主要动作"。
- 我怎么复：SC04 可以照这个骨架建一份我们自己的固定块，CUT 字段直接用。**"连续性"和"负面控制"两栏是我们现在缺的。**
- 何时借：所有多镜头长条（15–30s）。

## 二、逐场逐镜

### 场 A 夜河初遇（许翁出船 → 水鬼赶鱼 → 对话）

**A1 出船对喊（CUT1–8）**
- 画面：樵夫在栈桥喊话 → 反打河中许翁回应 → 过船身看远处樵夫 → 许翁侧面笑答 → 竹篙入水特写 → 边撑船边唱渔歌（7s）→ 风灯特写 → 船身贴水 → 90° 垂直俯拍孤舟驶入黑夜。
- 为什么：对话用"岸/船"两个固定空间来回切；之后用三个物件细节（竹篙、风灯、船身）把夜航串起来，最后一下拉到垂直俯拍，尺度突然变大。
- 怎么复：固定块里专门写"空间关系统一修正"——樵夫始终在陆地一侧、许翁始终在船上渐远；唱歌那镜写"不是念歌词，是唱出来；不要戏曲唱腔、不要乐器、不要和声"。
- 何时借：两人隔空对话；用物件细节过渡；场尾用俯拍孤立主体收束。

**A2 水鬼登场（CUT10–17、CUT01–02 捕鱼）**
- 画面：水下仰视，前景水鬼掠过、后景船底滑过 → 许翁往河里倒酒、自己喝一口 → 水下酒液化成气泡 → 被锁的双脚特写 → 水鬼闻酒、睁眼、翻身游走 → 水鬼主观追鱼 → 抖动肩胛骨铁链赶鱼。
- 另一条：鱼自然游 2 秒，最后 1 秒一只手抓走；然后严格正背面拍水鬼啃食，不见脸。
- 为什么：**先让观众知道"船下有东西"，但不给看清**；酒是把两个世界连起来的线索物。
- 怎么复："前景快速掠过，不做清晰正面展示""不要让观众提前看到水鬼""镜头永远保持正背面，残忍感来自背、肩、手臂"。
- 何时借：未露面的存在；用气味/声音/物件触发另一个空间的反应。

**A3 船头对话（CUT24–41）**
- 画面：手蹼搭上船沿（后景许翁还在拉网）→ 许翁手上一顿、轻笑"多谢小友赠鱼" → 俯拍水鬼浮出脑袋"你~不怕我？" → 许翁拿酒走到船头"来，上来" → 水鬼摇头，转身露出肩胛骨铁链 → "哟！怎么锁着呢？" → 六郎讲受罚 → 水下背面仰拍铁链延伸入深水 → 许翁"你~没救她？" → 六郎 17 秒悔恨独白，最后拍水 → 许翁递酒"喝点？" → 六郎"你这人……倒是奇怪" → 许翁站起大笑 → 90° 俯拍孤舟收尾。
- 为什么：许翁全程不怕，恐怖片的套路被反着用；最重的信息（被锁）用**转身露出铁链**交代，不靠台词。
- 怎么复：
  - 一行总结节奏：`手上一顿 → 镜头摇脸 → 轻笑 → 从容道谢`。
  - 长独白写比例：**"前 80% 压抑讲述，最后 20% 情绪裂开"**，每句台词后跟一行语气。
  - 台词的后半句落在别的画面上：判词后半句配"背影 + 铁链"，不拍脸。
  - 递酒接情绪："不讲大道理，用递酒这个动作把情绪接住"。
- 何时借：SC04 里任何"一人讲过去"的戏；用动作代替安慰。

### 场 B 阴司降罚（河底）

- 画面：**闪电视角从高空俯冲入水，沿铁链旋转追到六郎脚部（8s，FPV）** → 电流灌入肩胛骨 → 广角全身受刑 → 面部大特写嘶喊 → 鱼眼俯拍 → 脖颈铁链 → 头发 → 绷直的铁链 → 90° 俯视摔回河底昏迷 → 手边泥沙先震动 → 水面漩涡形成 → 阴司画外音"王六郎。" → 苏醒听见"轮回之机" → 过肩仰看漩涡听条件 → 喜色慢慢出现 → 漩涡消散 → 从脸下摇到脚上铁链，OS"是谁……要来替代我？"
- 为什么：阴司**始终不出实体**，只有漩涡、水流、声音；受刑用一串局部补镜（背、脸、颈、发、链）拼出来。
- 怎么复：
  - 长镜头写"必须完成的链路"：`高空俯冲 → 破水 → 气泡 → 铁链 → 旋转追踪 → 脚部`。
  - 表演写编号顺序：`1 头向后抽 2 眉紧 3 咬牙 4 下颌抖 5 张嘴 6 喉嘴抽搐 7 气泡 8 电流增强再抽一次`。
  - "让环境比人物先察觉"：昏迷的手不动，指尖旁的细沙先震。
  - 情绪不要一步到位："不是立刻狂喜，而是先不敢信"；"不是立刻道德挣扎，先是疑惑"。
  - 本场情绪链写进连续性：`电刑 → 阴司降临 → 轮回希望 → 条件出现 → 疑惑`，最后一镜当下一场的钩子。
- 何时借：看不见的权威/力量；场尾留疑问。

### 场 C 少妇过桥（暴雨）

- 画面：桥头 90° 俯拍赶到 → 从婴儿上摇到脸 → 少妇主观看危桥 → 回头看身后再决定（"囡囡不怕……娘带你走"）→ 试探踩桥 → 桥猛晃 → 六郎水下主观第一次看到她 → 六郎探出半个头 → 横移跟随 → **150mm 长焦，前景破口转焦到后景走来的少妇** → 狂风吹歪伞 → 脚踩破竹面 → 麻绳散开 → 90° 俯拍升格桥断坠下 → **8 秒横移"先误导再揭示"** → 婴儿惊哭 → 拉回桥面 → 六郎水下主观 → 弓身赶路 → 断桥空镜 → 过肩冲最后一段 → 升格跨上岸 → "我们过来了"话音刚落桥被冲走 → 转身滑倒 → 滑向洪水 → 抓泥抓不住 → 把婴儿抛进树根夹缝 → 婴儿大哭 → 滑入河 → 被冲远。
- 为什么：危险一层压一层，每次刚安全就来下一个；观众比人物先知道危险（破口转焦）。
- 怎么复：
  - 横移揭示：前半段只拍晃动的竹杆、浪、麻绳，不见人；一只手先出现，再横移才看到她挂在桥外、单手把襁褓举高。
  - 双线动作 + 本能优先："先张手找平衡 → 发现孩子要撞地 → 立刻收回，把孩子举高"。
  - 每个动作写"失败再试"：抓泥被刨开 → 抓石头石头也松 → 伸向树根差一点。
  - 追她的人不出画："她像在担心有什么东西追来，但画面里不要真正出现"。
  - 空镜也有任务："无人物。重点是让观众意识到这座桥接近彻底崩溃。"
- 何时借：SC04 若有"发现/险情"戏，用转焦让观众先知道；用横移做延迟揭示。

### 场 D 六郎救人（水下）

- 画面：少妇抓短竹竿被冲走（**镜头跟着一起向下游，后景河岸反向掠过**）→ 六郎看、冲出去 → 铁链骤然绷直把他拽停 → 脸摇到绷直的手臂，差一点够到 → 肩胛骨锁钉特写 → 半水上半水下，竹竿被冲走 → 三次发力 → 锁钉被硬拔出 → 魂魄重影被撕离 → 双肩同时挣脱 → 上半身扑出仍被脚链拖住 → 少妇的手沉入水面 → 缺氧下沉 → 回身解脚链 → 抬头望画外 → 举石砸链 → 铁链毫发无损 → 闭眼再睁眼，改瞄准自己的腿 → 砸、再砸 → 拖着残腿高速横移游去 → 两次才把少妇推上泥岸 → 仰面被洪水冲走，90° 俯拍升高。
- 为什么：障碍是具体的物（铁链），每次突破都付出身体代价；"决定"不靠台词，靠**先看铁链、再看她、闭眼、睁眼**。
- 怎么复：
  - 用运动视差证明"被冲走"：写明"不是固定特写，背景持续掠过"。
  - 少妇不入画的反应镜头："禁止出现少妇的身体、倒影、轮廓、虚影，只通过视线方向表现"。
  - 救人不能轻松："第一次推只动一点，第二次才上岸，手无力沉回水中""不要英雄姿态"。
  - 定性一句话："不是英雄凯旋，而是他终于完成了与百年前完全相反的一次选择。"
- 何时借：决定时刻；反应镜头里把对象留在画外。

### 场 E 百年前（妻子落水，六郎投湖）

- 画面：泥岸塌陷 → 升格坠水 → 六郎赶到 → 水中呼救 → 抓画卷施救（侧面、反打、水下双脚三个补镜）→ 漩涡 → 画卷撕裂 → 过肩目送被冲走 → 崩溃 8 秒（喊 / 捶地抽打自己 / 失力趴倒）→ 俯拍暴雨砸湖面 → 一镜到底起身投湖（10–17s，环绕上升，最后固定停 3–5 秒）。
- 为什么：画卷是两人之间"唯一连接物"，撕裂 = 失去；投湖写成"把自己交还给这片水"，不是殉情。
- 怎么复：崩溃分三阶段写；中间插一个无人空镜（"喊完之后世界没有回应，只有暴雨还在砸湖面"）；投湖"不要跳、不要冲、双手打开身体前倾慢慢倒下"，结尾"镜头不要马上结束，湖面恢复平静，仿佛一切没有发生"。
- 何时借：崩溃戏；用空镜当情绪的回声；结尾留静止。

### 场 F 告别与册封（夜河）

- 画面：许翁撒网到一半停住 → 水面涟漪空镜 → 过肩看六郎魂体浮出 → "六郎？" → 从脚摇到脸"是我，老翁" → "怎么这副样子？" → 六郎看着自己消散的手："这次……连这河……也留不住我了" → 90° 俯拍孤舟 → "悔么？" → "不悔～" → 手拿起酒葫芦 → 12 秒长镜头光液渡封（四句册封词）→ 河水飞来涌入 → 雾中化为河神 → 变身后看手、张合手指、转腕、挺直、看向许翁。
- 另一版告别（更早的设计）：六郎"明日我就走了""去投胎"，许翁"好啊！终于熬到头了"，六郎"最后一网给你赶满"翻身入水。
- 为什么：告别写得轻；最重的两句"悔么/不悔"前面先垫一个大俯拍留白。
- 怎么复：
  - 特效物质用"不是……而是……"定性：光液"不是普通酒水下坠，而是带灵性的液态光流"；青雾"不是浓烟，不遮脸"；水"不要从脚底直接冒，起点必须和六郎有明显距离"。
  - **变身后动作顺序固定**（防止模型摆 pose）：轻震 → 呼吸 → 抬手看手 → 张合手指 → 转腕 → 低头看身体 → 下降近水 → 脚下涟漪 → 放手 → 挺直 → 转头。负面："不要变完后僵在原地，不要像角色立绘"。
  - 每句台词配"表演补充"：说"这次"时看手；说"连这河"时抬眼看水；说"也留不住我了"时再低头。
- 何时借：SC04 的告别/和解；任何"状态变化"的镜头都可以写固定动作顺序。

## 三、这套提示词最值得学的：连续性专条

道具状态随剧情变，就在固定块里写一条"全场强制锁定"，每条提示词按当前剧情改写：

| 阶段 | 专条内容 |
|---|---|
| 被锁期 | 只有两组锁链：左右肩胛骨、双脚脚踝。手臂手腕腰颈都没有。露出肩胛骨或脚踝就必须有链，纯面部镜头可以没有 |
| 肩锁挣脱后 | 背部不再有任何铁链；只有脚踝仍锁着 |
| 砸断脚后 | 全身无任何铁链；双脚脚掌缺失 |
| 魂体期 | 手脚铁链都已不见；消散只能越来越明显，不能恢复 |

还有两类专条：
- **防畸形专条**："少妇只有两条手臂、两只手……禁止第三只手、腋下长手、襁褓旁凭空出现手掌"——抱孩子 + 撑伞的镜头专用。
- **防回潮专条**：每镜重复"禁止出现竹桥、残桥、桥桩"——因为桥断之后模型还会把桥画回来。

何时借：SC04 里任何会变化的道具或状态（开/关、在手/不在手、湿/干），都先列一张阶段表，再把当前阶段写进提示词。

## 四、这套提示词的毛病（生成前要避开）

1. **固定块整段重复粘贴两遍**（视频节点 8 一条里"全场参考图绑定…鬼身皮肤"出现两次）。
2. **固定块和分镜打架**：天气固定块写"浪头拍打桥面、桥身晃动"、美术块列了"竹桥"，分镜里却逐镜"禁止出现竹桥"。模型老画回桥，固定块自己就是原因之一。
3. **图号不统一**：全局写"图片 6 妻子、图片 4 六郎"，CUT 里却写"图 2 六郎、图 1 妻子"；同一角色在不同节点分别是图 4、图 6、图 3；参考行缺编号（"｜王六郎透明魂魄"前面是空的）；"生成失败的视频"那条所有图片和音频引用全丢了。
4. **聊天残留留在提示词里**："如果想更克制，也可写：No dialogue""接下来再进入 CUT12 会更顺""对，CUT09 这里空间关系要改清楚……"。
5. **读音解释写进提示词**（"囡，nan，第一声""寐 = mèi"）——可能被当成画面文字或台词。
6. **同一镜两种写法并存**：CUT40 一版写"水线上下分屏式"，另一版专门改成"不是分屏，是一个连续镜头"；CUT09 河神变身一版是"面部近特 → 仰拍全景"，一版是"高机位俯拍环绕"。
7. **表头时长与 CUT 时长合计对不上**：多条表头 30s，CUT 加起来不到；CUT15 投湖有 10s / 12s / 17s 三版。
8. **台词和"No dialogue"同时出现**（CUT13-B）；血量"少量 / 大量"在版本间互改，同一条里前后不一。
9. **焦段写成范围**（35mm—50mm），等于交给模型随机。

## 五、给 SC04 的可直接借用清单

1. CUT 字段加两栏：**连续性**（这一镜承接什么、为下一镜铺什么）、**负面控制**（点名最可能出错的那个版本）。
2. 道具/状态做**阶段表**，当前阶段写进固定块。
3. 表演写**顺序**（编号或箭头），情绪写**台阶**（先不敢信，再……）。
4. 台词旁边写**不要怎么说**（"不要质问感""尾音不要拖成调侃"）。
5. 反应镜头把对象留在画外，写死"不出现身体、倒影、轮廓"。
6. 长镜头写"必须完成的链路"。

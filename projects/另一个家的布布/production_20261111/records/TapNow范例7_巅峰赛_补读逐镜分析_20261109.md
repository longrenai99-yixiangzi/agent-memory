## 一、生日敲门（ca0bf / 091e3 / 77c32，15 秒）——「先听见，再看见」的三段式

**统一写法**：SCENE CONTEXT → ACTIVE REFERENCES（"100% 匹配参考图"）→ LOCATION MAP（前/中/背 + 机位位置）→ FIRST FRAME → FORMAT MODE（硬切点写死，"摄影机不自行加切"）→ OPTICS（每段 FOV 度数）→ CAMERA（高度、距离、速度）→ ACTION（逐秒）→ PERFORMANCE → PHYSICS → LIGHTING → AUDIO（逐秒）→ POSITIVE LOCKS。

### 镜1（0–1.5s / 0–2s）门把手侧面近景，完全静止，等声音
- 画面：门框占右 2/3，左边是虚化的室内烛光/空白墙；第 1.2s 三下敲门，门板轻颤，门把手抖 2 毫米。机位在门右侧、腰高（1.1m）、与门平面成 45°/平行，63°或29° FOV。
- 为什么：**先给「悬念」——观众只看到一个静止的门把手，是声音在讲故事**。门把手上"反着烛光的金属"是一个只在静帧里有生命的细节。
- 我怎么复：SC04 开场/任何「有人要来」：先拍门或把手 1.5–2 秒，声音触发；写「完全静止、等声音事件」。
- 场合：来访、敲门、电话响、等待。

### 镜2（1.5/2–8/7s）正对门中景缓推，人从画外跑进来
- 机位正对门、腰/眼高，4m→3m 以每秒 0.2–0.3m 缓推（ca0bf 写"推镜在 Selin 入画前 0.5 秒启动"）；孩子从右边深处跑入（1.5m/s，裙摆后扬 30°、有 0.1–0.2 秒惯性延迟），父亲跟入（0.8m/s，右手"慢点"手势，说话 "Slowly, Selin"），孩子急刹（右脚前撑、左脚跟上稳住、裙摆继续前摆再落回），按把手、开门（门向内开，门铰链声，走廊冷光射入）。
- 为什么：①**速度差**：孩子 1.5，父亲 0.8，跑与追的关系一眼看懂；②**推镜早于人入画**，让人"闯进"已在运动的画面；③开门瞬间用**冷暖色温分界线**（走廊 4000–5600K vs 室内 2400–3200K）。
- 我怎么复：SC04 里「人冲向某物」：写速度、急刹的足部顺序、裙摆惯性；缓推的速度用数字。
- 场合：奔跑、抢到门口、开门揭示。

### 镜3（8/7–15s）开门后，来人正面中近景，对话、拥抱、跳、牵手进屋
- 18°/47° 近景，机位退半步给门让位，手持 1–2cm 微晃，两个孩子拥抱→**原地同时跳两次（离地 10–15cm，落地"咚"，第二次幅度略小）**→牵手往房间深处走（脚步声渐弱），父亲让开（上身后仰而不是僵硬侧步）、"请进"手势、最后跟进，烛光里只剩剪影。
- 为什么：把「喜悦」拆成可看见的动作序列（捂嘴→扑上→拥抱→跳→牵手拉走），每个动作带一个声音；**跳两次、第二次略小**是真实感的来源。结尾"背影渐远 + 声音渐小"收束。
- 复用：SC04 里「久别重逢/终于找到」的庆祝可以用跳、牵手拉走来写，**不用笑脸特写**。

### 价值提取（对 SC04）
- 三版都把 **LIGHTING 写成色温数字 + 方向**（主光 3200K 左右交叉、门外 4000–5600K 勾边）；**PHYSICS 写成"惯性延迟/落地沉降/门板与门框间隙 5cm"**；**AUDIO 逐秒写**。
- 写法借鉴：只在「需要精确到秒的短戏」用这套 12 节结构；SC04 镜头单镜 6–8 秒不需要这么长。

## 二、Marco Polo 夜晚客厅（f7de7，15 秒，5 次硬切）——用 FOV 度数切换「温暖→危机」

| 段 | 时间 | FOV / 机位 | 画面 | 为什么 |
|---|---|---|---|---|
| CUT1 | 0–3s | 47°，侧前 4m，胸高，固定 | 父亲闭眼、双臂前伸摸索，夸张学羊叫 "Maaaa-a-arco!"，右肩碰椅子（椅子晃 2–3cm） | 建立「游戏」：身体夸张、嘴大，**闭眼 = 看不见危险**（伏笔）。固定机位让人在画里动 |
| CUT2 | 3–6s | 29°，沙发后 2.5m，机位降到 80cm（孩子蹲姿眼高），5° 俯 | 两个孩子蹲在沙发后，手捂嘴憋笑，肩抖（每秒 2–3 次），一人抓另一人袖口；**姐姐松手拢成喇叭状，正要发 "P" 音时冻结** | 孩子视角机位；**画面停在"将发未发"**，下一刀接异常 |
| CUT3 | 6–9s | **12° 超长焦**，茶几斜前 5m，桌面高度，三脚架死锁 | 前景玻璃杯 → 背景天花板压在同一平面；0.3s 后杯子高频抖（4 次/秒、1–2mm），杯中水起同心圆；1s 后天花板一点裂开→分叉 2–3 条（0.5s 蔓延 20–30cm）→灰粉像雪缓慢飘（50cm/s）；**背景里 Selin 的声音 "Pooo—" 只出半个音就被切断** | 12° 压缩把"杯子的抖"与"天花板的裂"放进同一画面；**用物体的微小变化代替地震特效**；声音被切断 = 情绪被切断 |
| CUT4 | 9–12s | 29°，Selin 正面 2m，蹲姿头高，前 1.5s 静止，后 0.5s 轻跟摇 | 手仍拢在嘴边，嘴型仍是 "o"，**目光突然改变**：瞳孔缩、眼睛睁开、眼球上转 30°，眉心收拢，嘴唇闭紧、嘴角下压（0.5 秒），然后**颈部带头猛转 90° 向右后（0.3 秒，头发滞后甩出弧线）**，手从嘴边落下、双臂向两侧张开，喊 "Defne!" | 注意力链：笑 → 视线上移（天花板）→ 眉眼变 → 头转 → 手变 → 喊。**表情变化被拆成 4 个器官依次发生**；结尾停在三分之四侧面视线朝右 |
| CUT5 | 12–15s | 63° 广角，侧 3.5m，高 1m，固定 + 末 0.5s 右移跟 10cm | Selin 深蹲前倾 45°，双臂前伸；0.3s 后后腿蹬地冲出（2–2.5m/s），0.8s 手掌按住 Defne 左肩，Defne 反应滞后 0.3s（先困惑，后惊恐），上身先动、臀腿滞后 0.1s，被推向右后；**停在"推与被推的动态平衡"的瞬间，不拍落地** | 广角把两人关系和路径放进一个画面；**动作停在张力最高点而非结果**（"保持动作的未完成"） |

- 为什么整体这样排：温暖镜头 CUT1–2 用普通焦段；**危机第一征兆用 12° 长焦压缩**；**情绪转折用 29° 人像焦段**；**行动用 63° 广角容纳路径**。作者自己在 STYLE 里写了："每个切点的光学选择服务叙事"。
- 我怎么复（对 SC04）：想表达"平静中第一个异常"→ 用长焦固定拍**一个小物体 + 背景上的一处变化**（杯子+天花板），**不让人物出现**；然后切到人脸拍"察觉"；再切广角拍"反应行动"。
- 场合：地震/异常前兆、鬼影出现的第一征兆、门外有声。
- 局限：**写了 31675 字（含大量物理数值），可能使模型过载**；该条是 draft 480p，成片质量需看实际成片。作者写到 "pupil 4mm→2.5mm"、"150–200 Newtons" 等数据，**模型未必理解**，借鉴时只取：FOV 度数、机位高度、事件先后顺序，不抄物理数值。

## 三、泳池系列

### f9d8f / 01606（15s，一个机位，切点只在 7.4s）——**匹配切：泳池水下的小女孩 → 废墟中蜷缩的小女孩**
- 写法要点：**"全片一个机位，切点只有一处"**；两段"29° 视角完全一致，切点前后景别与构图完全一致"；"切点落在那只手掌扫过镜头的同一瞬间，与她的闭眼状态严丝合缝"；"同一构图、同一景别、同一面部位置"；声音在切点"接上低频轰鸣、碎石滚落声、粉尘洒落声"。
- 0–2.6s 女孩浮在水面正面看镜头，笑，深吸一口气，闭眼；2.6–4s 头先入水，**摄影机随之越过水线**；4–7.4s 水下继续下沉，气泡沿画面左侧上升；6.6–7.4s 一只张开的手从画面上方虚焦入画盖住右上角；**7.4s 切点：手掌盖满画面的瞬间 → 废墟中另一个女孩闭眼蜷缩，粉尘被气流掀起后沿光柱沉降**。
- 为什么：**用「手掌遮挡」做匹配切的遮掩，两个人脸位置/大小/闭眼状态对齐**；"闭眼"是桥（憋气闭眼 ↔ 惊恐闭眼）；光从日光到柔蓝到光柱的色温变化（5600K → 水下冷蓝 → 6000K 硬边光柱）。
- 我怎么复：**这正是 SC04"现实 ↔ 另一个家"转换的又一种方法（遮挡匹配切）**：用手/物体遮住镜头的瞬间 + 两侧同一位置/景别/闭眼，声音在切点处接上另一个世界的低频。和范例 6 的"眨眼匹配切"并列。
- 场合：时空切换、平行世界、闪回。

### 39f11 / 91e4a / 145ce（6s，一镜到底）——「手机放在池边录像」当作叙事装置
- 画面：0–1.8s 一只手把水瓶放稳，把手机立在瓶前（屏幕朝摄影机，后置镜头朝泳池，**手机屏幕显示实时取景和录像红点/计时**），手退出；1.8–3s 摄影机沿道具左侧缓慢前移（累计约半米），**焦点从手机平滑移到池中央的涟漪**，手机瓶子虚化并因视差移向右下角；3–5s 女孩从水中浮出（脸→湿发→肩依次），闭眼、抹一把脸；5–6s 睁眼看向手机，嘴角扬起；摄影机减速停稳。
- 版本差异：39f11 为 "近景"，只写手机"实时取景"；**91e4a/145ce 为解决"大泳池的尺度"问题，反复写"女孩位置在大水面中央、前后左右有充足水面、两侧池岸延伸"**——说明模型会把大泳池画小。
- 为什么：**「手机=观察者」：让画面里的某个物体承担"拍摄者视角"**，女孩看向手机 = 看向摄影机；焦点转移（rack focus）把注意力从道具带到事件。
- 我怎么复：SC04 里监控/手机/镜子当"第二个镜头"，用 rack focus 从物体转到人物。
- 场合：家庭录像、监控、手机拍摄的回忆。

### a0102（26s，四段手持，切点 7/16/23s）——父女泳池叫名游戏
- 关键写法：**父亲的正脸始终留在画面之外**，"整段表演由后背、肩胛、手臂和双手承担，形象以背影、逆光侧脸剪影或前景焦外虚影出现"；**焦点永远落在女儿身上**；远处戴柠檬黄泳帽的小女孩是"最远的黄色色点"，作为空间尺度锚。
- 镜1：84° 广角贴水面，**水线横切画框**，上半水上（碎光斑）、下半水下（青绿 + 光网），机位以 2km/h 前推越过池沿压上水面，5.0s 一串气泡 → 女孩破水而出，水珠溅上镜片。
- 镜2：过肩，47°，他的湿肩压掉画面左 1/4 并柔化，焦点咬住女孩的脸；两人泼水、说 "Okay, new game. I say Marco, you say Polo. Ready?"。
- 镜3：前段 29° 逆光侧脸剪影，后段 18° 反打女孩近景（20.0 秒内部硬切）；父亲拢手 "Maaaa-arco!"，女孩 "Pooo-olo!"。
- 镜4：63° 观察式广角贴水面，父亲背影伸手摸索，女孩一边划水躲开一边捂嘴偷笑，远处孩子应声。
- 为什么：①**不拍父亲的脸，减少人脸一致性风险**，同时让女儿成为情感中心；②**镜 1 的"半水上半水下"** 是 "泳池戏" 的招牌构图；③声音场"从第一段一直贯到结尾"，连续。
- 我怎么复：SC04 里如果某人物脸一致性有风险（如丈夫），可大量用背影、肩胛、手；焦点永远在妻子身上。**对 SC04 的现实意义最大的一条**。
- 场合：不想露脸的家长/第三者；亲子戏；水边戏。

### f56e8（4s）"近景特写各种快闪快切，三人水中玩耍，全是手持晃动镜头"——54 字的极简提示词

### da4d2（7s，固定机位）机械狗被卡在缝隙——「先空镜，后入画」+ 画外声
- 画面：首帧只有空缝隙（40cm 宽、锯齿混凝土、外露钢筋，顶上斜光）；0–1.5s 无运动主体，画外男声（AI 合成、带数字失真）"Selin? It's Papa."；1.5s 机械狗头从画面上方探入；头部四个传感器镜头依次亮白点；身体前推，肩卡住；3.5–5.5s 四肢发力挤压，装甲变形，缝隙不够，**卡住**；5.5–6.5s 挣扎震落缝边灰尘，爆成灰云；6.5–7s 停止，灰云变薄，光穿灰成光束。
- 为什么：①**固定机位 + 对准缝隙中轴**，让观众的眼睛只盯"能不能过"；②**失败是情节**：POSITIVE LOCKS 写"机械狗始终卡在缝隙口无法穿过，身体不缩小，缝隙不扩大，挣扎真实但不成功"；③画外喊话的"电子声"表现这是机器代替人说话（情感被媒介稀释）；④灰尘写成"从缝隙边缘四周爆发"，而不是"从画外飘入"。
- 怎么复：SC04 里「想进去但进不去」「看见不该看见的缝」：固定机位拍缝，**前 1.5 秒留空**，声音先入；失败要在提示词里写明"不成功"，否则模型会让它挤过去。
- 场合：门缝、窗缝、打不开的门。

### 41bfc（30s，一镜到底「敦刻尔克式调度」）——**无人机起幅 → 俯扣 → 贴身跟拍 → 地面环绕 → 推到手机 → 对焦转移 → 升空收镜**
- 分段：0–5s 直升机从左前景掠过，镜头随之横移后俯扣下降；5–10s 下降中显露四十多名救援人员围成大圈（"面孔各不相同、制服统一"）；10–14s 由俯拍转平，咬住队长布拉克，贴身跟拍；14–19s 布拉克在盖灰布遗体旁停下蹲下，镜头降到地面高度并微微环绕，他一根根掰开死者手指取出碎屏手机，**快速推镜咬住屏幕（锁屏是父女泳池合照，裂纹穿过女儿的脸）**，再**垂直搓焦上移到布拉克的眼睛**；19–24s 年轻队员报信（台词），布拉克吼 "Then why is everyone standing around? ## 六、这一批对 SC04 的直接用法（汇总）
1. **匹配切四连接点**：形（脸位置大小）、神（闭眼/眉间竖纹/害怕）、动（头发/物体运动矢量）、声（低频撞击咬合）。
2. **离散焦段递进**：63° → 47° → 29° → 18°（环境 → 人 → 脸 → 眼）。
3. **缝隙/门/洞** 的写法：固定机位对准中轴，前 1.5–2 秒留空，声音先入；失败写明"不成功"。
4. **看不见的存在**：镜头守着空处，等待不剪，回应用画外声，人物反应承担戏。
5. **屏幕只做信息位**，用"首帧锁定 + 文字写死"；手机屏幕不可靠。
6. **每条结尾用固定俯拍大全景锁站位**，供下一条衔接（d749d、2537d 的 29–30s）。
7. **不露脸的角色用背影/肩/手**（a0102），焦点永远在主角身上。

## 九、本批对 SC04 的直接用法（汇总）
1. **模板可抄**：`参考图职责 → 色卡（色号） → 整体环境 → 空间关系 → 镜头叙事（每镜一事一句台词） → 执行重点 → 最后一格固定俯拍锁站位`。
2. **色卡写十六进制**，每条重复，统一影调。
3. **揭示链**：高兴 → 光停住 → 一句话 → 局部逐段 → 第三人确认 → 留反应；观众在台词前不能看到被揭示的对象。
4. **触摸同一物件的硬切闪回**，不用特效，影调统一。
5. **隔障碍对话**：障碍物始终存在，只露声音和一只手，接触分步骤；沉默"不能被剪掉"。
6. **熟悉的声音出现=恐怖**：机械重复的节奏 + 身体拒绝。
7. **设备/屏幕一个物件一个功能**；红字与语音同时出现；重复台词一字不差。
8. **接触写两步**：先托指尖，再握掌心；喊话写"先停钻再听"这样的因果。

## 十二、本批汇总的可借用技法
1. **设备按顺序失效**：亮屏→相册→播放→故障→黑屏→声音继续→卡断；声音掉字制造紧迫。
2. **探测光束正对镜头 0.4 秒扫过**（丁达尔），让观众成为被探测对象。
3. **单镜头主体转移**：rack focus + 缓推 + 前景人物出画；注意"焦点移动发生在谁的动作之后"。
4. **誓师模板**：疲惫的听众 → 一个眼神 → 8 秒固定仰角台词 → 行动代替掌声 → 人物走入环境。
5. **"录像手机"只做角落红点**，不要求读屏。
6. **"摄影机不下水/不分屏"这类禁止项要写明**，模型会自作主张生成特效分屏。

### 画布 7 的十条总结（SC04 可直接抄）

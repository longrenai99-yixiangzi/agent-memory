# 《另一个家的布布》SC01｜C01A–C01B 动态跟拍三维预演执行方案 V0.4

> 日期：2026-10-28  
> 状态：**导演候选／待三维预演验收**，不是最终机位或剪辑定稿。  
> 执行方：Codex（在**现有 Blender 工程和已有预演脚本所在项目**内执行）。  
> 适用范围：**只重做 SC01 开场 C01A、C01B 的镜头与人物动作预演**；其余 C02–C10 和已确认剧情不改动。  
> 版本关系：本稿在 C01AB 预演执行方案 V0.3 基础上改进，**不替换已保存的 SC01 全场镜头设计 V0.2**。  

## 0. 一句话导演目标

**第一秒就贴近一个正在做家务的妻子，用真实移动的摄影机陪她沿茶几擦拭；她转向沙发时做一次明确切镜，转为更易看清动作的中景，拍她顺手把毛毯抚平，随后自然转头向书房里的丈夫喊话。**

目的不是展示一套漂亮的室内模型，也不是让妻子从远处走来“执行整理毛毯的任务”，而是让观众从人物行动进入生活，再自然记住“毛毯已经被她整理平整”。

## 1. 与上版预演相比，必须纠正什么

| 上一轮问题 | 本轮必须实现的变化 |
|---|---|
| 开场先给空客厅／宽景，人物后来才入画 | **开场第一帧就是妻子正在擦茶几的近景**，不得先插入空客厅镜头 |
| 人物走动但摄影机基本原地不动 | **C01A 摄影机必须真实改变三维世界坐标，跟随妻子移动**；不能只有人物朝静止摄影机走、原地摇镜或数字缩放 |
| 只是人物的侧面近景，没有“跟着人一起走”的观感 | 摄影机保持**正面偏侧的近距离人物视角**，随人物沿茶几移动，并在她身体转向时连续调整位置与朝向 |
| 开场动作像专门走过去整理毛毯 | 擦茶几与整理毛毯是**顺手连续的家务行为**，不得额外添加为走位而走位的长路段 |
| 毛毯整理动作难以读懂 | C01B 至少看清手接触毛毯、抚平、离手，以及整理完成后的相对平整状态；已有毛毯模型可复用 |

**本轮最高优先级是“有真实空间位移的贴身跟拍 + 一次动机明确的景别切换”。** 毛毯真实布料动力学和角色面部细节可以简化，但关键接触与状态变化不能完全缺失。

## 2. 已确认的空间与项目约束（不得自行改写）

- 使用当前项目中用户已确认的最新 `.blend` 房屋白模，以及现有妻子角色／占位模型、沙发、茶几、毛毯、绿植、书房方向。**不得另建不同户型、挪动家具、镜像房间或重新解释墙门窗布局。**
- 空间真实尺寸以已有 CAD／正式白模为准；家具按最终批准布置。此前预演曾出现家具、植物挡住关键动作的问题，新机位应通过摄影机布置解决，不要为迁就镜头擅自移走绿植。
- **茶几位于沙发与电视柜之间。** 本版建议从茶几靠电视柜的一侧开始擦拭；但最终的站位侧、移动方向、是否有足够通道，以白模实际可达性为准，不能臆造固定东南西北方向或距离。
- 开场人物正在家中做睡前简单整理。不是大扫除，不增加复杂道具或无意义家务任务。
- 妻子之后需自然转向书房，引出“你还不睡啊？”及后续已讨论台词。**不要改写台词、把同一句台词在 C01B/C02 重复播放，或擅自改 C02 的剧情。**
- 场景正式视觉母版与角色资产仍然有效；当前测试可用低模占位，但人物的脸朝向、肩膀、手部、重心、脚步必须足以判断镜头与动作。

## 3. C01A｜贴近妻子的真实移动近景（首选约 3–4 秒）

### 3.1 第一帧与构图

- **不拍空镜，不从全客厅建立镜头开始。** 第一帧妻子已经在茶几旁擦拭。
- 摄影机位于妻子**正面偏侧**，优先试三分之二侧脸的角度，而不是纯侧面、纯背影或正对镜头的证件照式构图。
- **景别：** 近景／中近景候选。画面应能看见妻子的头部、肩背与至少一只正在擦拭茶几的手，必要时稍放宽景别；不能为了“特写”只剩一张脸，让观众不知道她在做什么。
- 背景只需有部分客厅环境信息；空间通过摄影机运动逐渐展开，不要求第一帧交代整个户型。

### 3.2 人物动作（要自然连续）

1. 开始时妻子已俯身或微微前倾，在茶几表面进行一段实际可见的擦拭。
2. 她沿茶几可达的方向移动一小段，继续擦拭同一件家具；不是原地重复机械摆手。
3. 擦拭动作逐渐收束，注意力转向沙发上的毛毯。
4. 她开始转身／迈向沙发；在这个**有动机的动作转折点**与 C01B 衔接。

动作不必把整张茶几擦完。**用少量但可读的擦拭行为交代她正在收拾客厅，不能为了展示跟拍故意拖长家务。**

### 3.3 摄影机运动：这是必须验收的重点

- 使用真正的 Blender 摄影机对象（或其父级 Rig / 路径约束）**随人物同步平移**；摄影机的世界坐标必须发生连续变化。
- 人物移动时，摄影机与她的相对距离维持在近景可读范围，允许轻微变化，不需要机械地锁死人物占画面比例。
- 人物转身时，摄影机应有相应的移动与取景调整；**允许转动摄影机，但转动不能替代平移跟随。**
- 画面背景应能看到合理的**运动视差**：茶几、沙发、电视墙等随着相机位移呈现不同的相对位置，而不是像固定监控机位一样背景不变。
- 运镜平稳、克制，有人物陪伴感；不要为了证明摄影机在动而环绕一整圈、猛推拉或手持乱晃。
- 镜头全程保持同一条连续摄影机运动轨迹。**不要用多个固定机位拼接冒充 C01A 的连续跟拍。**

### 3.4 出镜／切点

- **切点：** 妻子擦拭结束，目光／身体自然转向沙发，开始迈步或转身的那一瞬间。
- A 最后一个动作状态应与 B 的开头状态相接，保证脚点、头部朝向、手部位置、运动方向连续。

## 4. C01B｜转身切到沙发中景，整理毛毯（首选约 4–5 秒）

### 4.1 机位与构图

- **必须发生一次可辨认的剪辑切换。** 从 A 的人物近景，切换为人物与沙发同时清楚可见的中景／中全景；不能仅拉远 A 摄影机当作切镜。
- 摄影机选择可以清楚看到沙发坐垫、毛毯和妻子手部活动的位置。允许固定，或仅在角色起步时做极小的构图调整；**本镜的职责是看清整理动作，不需要再展示一次显著跟拍。**
- 具体摆在哪一侧，应由现有白模的沙发、茶几、绿植、门口关系来定。避开真实遮挡，但不移动家具。
- 不要让妻子正好挡住毛毯；人物入画比例必须足以辨认“从茶几转向沙发、顺手整理”。

### 4.2 人物动作与毛毯状态

1. **承接 C01A 的转身／迈步**，妻子到沙发旁，动作不要突然重置。
2. 她注意到毛毯略乱，自然伸手，接触毛毯；不需要夸张皱眉或“侦探式”观察。
3. 手沿毛毯表面短促抚平，手移开后，毛毯保持整理好的状态。
4. 妻子直起身，自然转头／回头朝书房方向，准备问丈夫睡不睡；这一下是连接 C02 的叙事桥。

**毛毯已有模型但缺少形变动画：** 优先采用简单 Shape Keys、局部骨骼控制或其他低成本可控方法表示“略有褶皱 → 手抚平 → 平整”。避免手未接触就自动变平、手穿过布料、毛毯整体瞬移。若本轮确实无法做形变，至少用明确的手部接触动画和状态标注替代，并在交付说明中写明“布料形变尚未验证”，不得说已通过。

### 4.3 与 C02 对白的接口

- C01B 末尾需要看见妻子**自然回头朝书房方向喊话的表演起势**。
- 若此次白模只验证动作，可用时间标记／临时字幕表示“你还不睡啊？”。若实际加临时台词，**本句只出现一次**；后续 C02 需从正确的对话位置接上，不得重复。
- 不用为了完成台词强行把书房、丈夫都塞进 C01B 画面；C02 本来承担书房双人关系的交代。

## 5. 连续预演的建议节奏（可根据动作调整）

| 段落 | 参考时间（非硬规定） | 主要信息 | 摄影方式 |
|---|---:|---|---|
| C01A | 0:00–0:03 / 0:04 | 妻子已在擦茶几，沿家具移动，镜头始终贴身跟随 | **运动近景**，相机真实三维平移 |
| 切点 | 约 0:03–0:04 | 擦拭结束，开始转身看向沙发 | **明确硬切**，保持动作方向与脚点连续 |
| C01B | 约 0:04–0:08 / 0:09 | 妻子靠近沙发，手抚平毛毯，直身回头喊话 | **中景／中全景**，以清晰动作和毛毯为重点 |

合计暂按 **7–9 秒**设计；如果自然的身体运动需要更长，不要为了卡秒数加速到机器人动作。反之，若镜头看起来拖沓，应先删无效动作而不是加快摄影机。

## 6. Codex 在现有项目中的执行步骤

1. **先读取**现有 `.blend`、上次 C01 预演对应的 `.py`、已有角色和相机对象、渲染脚本；本次在它们的基础上修订，不从零重建客厅。
2. 检查茶几靠电视柜的一侧是否有可行的擦拭站位，以及人物从茶几转到沙发的路线；如站位不可达，**保持家具不变**，在同一个真实空间内调整人物起点和摄影机路径。
3. 新建或调整 `C01A` 摄影机 Rig，关键帧驱动其**三维位置与朝向**；确保角色沿茶几的走位也有对应关键帧。不要仅给 `rotation_euler` 或焦距打关键帧充当跟随。
4. 建立 `C01B` 独立摄影机和相应镜头动作，验证 A 的末帧与 B 的首帧衔接。给必要的手部和毛毯状态变化打关键帧。
5. 使用 Blender 的相机标记／VSE／其他可复现方式，把 A、B **实际剪成一段可连续观看的 MP4**，而不是静态截图串联或两个文件让用户自行想象。
6. 先低成本渲染白模预览，按下文标准自检；发现碰撞、遮挡、假跟拍、空间跳跃时，**只修失败部分**，不擅自改剧情和家具布局。
7. 确保项目脚本可重复运行，保存新工程和所需参数／对象命名；不要覆盖已通过或作为对照的旧版工程与视频。

- `SC01_C01AB_previs_V04.blend` —— 可编辑的新工程，含角色动作、C01A/C01B 摄影机和毛毯状态；保留已有布局。

- `SC01_C01AB_review_V04.md` —— 简短的检查报告：实际时长、相机 A 起中终世界坐标、截图时间点、遮挡／碰撞、毛毯是否完成形变、未通过项。

若不能完成某项，明确写“未完成及原因”，不要以静态渲染图冒充三维动画，不要把尚未出现的动作写成已通过。

## 8. 本轮验收清单（按优先级）

### P0｜必须通过，否则退回修正

- [ ] **第一帧就是妻子正在擦茶几的近景**；脸部／头部方向和擦拭动作均可辨认，不从客厅空镜开场。
- [ ] C01A 是连续真实移动的摄影机：A 起、中、终三处**世界位置不相同**，背景产生合理视差；不是原地摇镜、缩放或人物单独走动。
- [ ] C01A 始终让观众感到“摄影机跟着妻子做家务”，人物没有长时间丢出画面，也没有严重遮脸／撞镜头。
- [ ] A→B **确实存在镜头切换与景别变化**：贴近人物的运动近景 → 展示沙发和动作的中景。
- [ ] A、B 的人物脚点、朝向、转身方向、手中物状态连续；没有空间瞬移或穿墙穿家具。
- [ ] C01B 能看懂“妻子整理沙发毛毯”，手部接触成立；毛毯若尚不能形变，报告明确告知。

### P1｜优先争取，验收时比较

- [ ] 擦茶几的动作简短自然、不机械，不因额外绕行拖慢开场。
- [ ] C01B 整理结束后能看出毛毯最终相对平整，为后面 C06 褶皱变化建立视觉基准。
- [ ] 妻子回头朝向书房的动作自然，为 C02 铺垫而不重复整场对话。
- [ ] 植物、沙发和茶几不遮挡关键动作；不存在为迁就机位而擅自调整家具的问题。
- [ ] 灯光可用白模基础照明；暂不以写实皮肤、材质、精细雨效作为否决条件。

## 9. 禁止偏差

- 不要再次使用“固定广角客厅 + 妻子从远处走入 + 走过去弯腰”的旧版开场。
- 不要把静止机位的人物近景误认为“跟拍”，也不要只用摇镜／变焦替代真正的相机三维位移。
- 不要把整段做成单一机位、完全没有 A→B 切镜。
- 不要为了展示运动让妻子反复擦很多家具，或加长无意义行走。
- 不要擅自改文学剧本、既定夫妻台词、书房位置、客厅家具关系。
- 不要只给机位图、首帧、九宫格或静态关键帧；**核心交付物必须是实际连续播放的 Blender 三维动画。**

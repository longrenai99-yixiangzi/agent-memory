## 摄影参数与构图边界

- A 约 50mm、F2.0、机高 1.40 米；B/C 约 35mm、F2.8，机高分别约 1.65/1.46 米。焦段和光圈是本版摄影目标，**不是 V1.1 Blender 的实测参数**；V1.1 分别为 22/24/35mm。给出的高度沿用 V1.1 相机高度作候选，不代表新焦段在原位置已验证。
- 较长焦距可能无法同时容纳原场景内的人物、过肩前景与屏幕；需要实测镜头、景深和设备净距，尤其 C 机附近门扇。若有冲突，应调整机位或焦距并说明，而不是移动家具或宣称已通过。
- B 妻子头部占画高20%—25%、丈夫前景占画宽15%—25%；C 丈夫头部占画高20%—30%、妻子前景占画宽10%—20%均是构图目标，尚未经本版机位实渲染验证。
- 为保持 A→B 的动作切点，A 末头部已开始回转，B 起头部只写“已部分回头”，身体和椅背处于跟转状态。不能把 B 起点写成回头已完全结束，否则会掩盖切镜时姿态不连续。
- 妻子在最后一句中处于 C 机左侧过肩前景，提示词只安排侧头与肩部微动等可能在轮廓中可见的倾听反应，不虚构看得到她正脸；具体视野是否能读到反应仍需实测。
- 游戏屏幕的“虚构画面、无可读文字和品牌”只约束屏幕，原有室内标牌和装饰不因此删除。
- V1.1 白模为候选，动作和真实眼线、站位与房间图的精确配准、C机设备净距以及生成时18秒的对白节奏尚未验收。V4 与 V3 的实际生成效果也尚未对照；采用状态式表达是本版创作策略，尚不能认定 Seedance 一定更擅长该写法。
- 主提示词新增的“后续声音衔接”位于 C02 约18秒内容之后，是给下一段或后期剪辑的接续说明；如果只生成约18秒的 C02，该段结束后的声音不会自动成为已生成的音轨。可将 `下一镜_声音衔接提示词.txt` 用于下一段，再与 C02 剪辑；妻子出房间与衣架声的相对时间尚需实际试听与导演确认。
- 声音在合理的时间省略之后按椅子、脚步、衣架和衣物组织；不能让还在画面里坐着的丈夫同时被听作已在阳台取衣，也不能用声音证明他是否碰过沙发。仅提示阳台/客厅之间没有门，不擅自取消其他门的物理状态。

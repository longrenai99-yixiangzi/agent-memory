## 1. 本轮导演意图和最新文本

夫妻睡前的生活对话：丈夫在电脑前打游戏，妻子从门口问话并提醒查看阳台衣服。丈夫听声后，**头部先向自身左后方的门口开始转，视线极短暂留在屏幕，随后视线跟向妻子，肩、身体和椅子再顺势跟转**；不是只拧脖子，也不是骤然停止所有动作。妻子从门口向内约半步并站稳，丈夫保持坐在原座位中心，椅子转动时手可自然离开鼠标。全程丈夫不佩戴或摘取耳机。

本轮对白顺序：妻“你打完没？”→妻“你还有多久？”→夫“打完这局。”→妻“那你打完去看看阳台的衣服干了没。”→夫“没干吧，连着下了好几天雨了。”丈夫第一句有一瞬犹豫，眼神略游移后回到妻子；妻子提醒时轻微无奈与让步；丈夫最后一句是不确定的日常解释，不演烦躁或被冤枉。

最新设计为固定 A 丈夫侧前近景、B 丈夫右侧前景过肩拍妻子、C 妻子左肩前景过肩拍丈夫，A→B→C→B→C，A→B 在丈夫回头动作中切。B 妻子面部与上身要清楚、不贴边、不被门板挡住；C 妻子前景不挡丈夫脸，视线和座椅方向跨镜连续。B/C 构图比例与真人眼神尚未实际通过。

## 3. V1.1 实证、范围与未解决问题

- **真实文件：** 16:9、960×540、24fps、435帧、18.125秒；A→B→C→B→C 切点为 3.125、6.000、8.250、13.333 秒。五句语音为 Windows 合成占位，MP4 含音轨与字幕；工程保存镜头及动作标记，语音 WAV 作为[独立文件](previs/audio/)提供，**未嵌入 Blender 音轨**。工程图像纹理被打包；本次只核过源工程，跨设备全量打开/重渲染仍待验证。
- **站位及轴线：** 妻子 `(8.50,0.64)` → `(8.85,0.64)`，约0.35m；三机位对随站位变化的轴线采样均在同侧。具体机位、焦距和[俯视示意](previs/stills/C02_V11_机位轴线俯视.png)见[工程说明](previs/预演说明.md)。同侧不等于屏幕视线、情感或剪辑通过。
- **身体动作：** 椅子与上身最终绕原中心约45°，头相对身体约95°，头部朝向与妻子平面方向约差11°；45°高于原15°–30°初始参考，头颈仍偏大。椅座中心逐帧数值漂移0；白模无独立眼球、完整骨骼或真实脚部支撑，不能声称自然对视、步伐或真人可实施。
- **有限碰撞检查：** 第1、76、90、105、110、132帧的部分人物与门墙、椅子与指定家具网格表面采样无交叉；不是全帧人体／设备包络、内含或真实净距证明。C机10厘米射线采样命中门扇，摄影机、支架和操作者落位未通过；B机设备包络也未核。
- **画面仍待审：** B 门板仍明显、丈夫右侧前景有裁切；C 妻子左肩前景与丈夫脸是否足够清楚、是否达到自然三分之二侧脸，需导演看真实输出；固定机位与过肩视线还需以最终房间几何复核。
- **参考图和工程不是同一批准链：** 用户确认带电脑桌的 `ENV-BED-001` 卧室是丈夫打游戏的房间，但图片与 Blender 门洞／尺度／整体平面尚未完成配准。原图采用范围为可见空间，色调仍需调整；[调色图](scene-review/ENV-BED-001_夜景调色候选_v01.png)是AI编辑候选，不是已批准的最终调色或原图替代。

## 4. 提示词及剪辑接口的经验

1. **一份可追溯的素材映射。** [V4.3 提示词](prompt/SC01_C02_Seedance25_提示词_V4.3.txt) 与[上传说明](prompt/使用说明.md)按 `@图片1–8` 标注本交接包 `prompt/references/` 的真实文件；妻子最新指定五官、妻子衣装、丈夫五官/三视、卧室原图、游戏参考构图、雨夜气氛与拖鞋职责分开。游戏机位图不能覆盖卧室；光影图不带入猫、家具或过暗曝光。原图、AI候选和确认状态分开。
2. **省文字不能删关键先后。** V4 精简时遗漏“头先动、视线仍短暂留屏幕”，用户指出后于 V4.1 补回；V4.2 补丈夫迟疑眼神。保留因果、方向和切口状态；表情用少量可见动作引导，避免规定大量肌肉步骤。是否由 Seedance 按要求执行仍需真实试片，不把文本检查当作生成质量。
3. **拍摄参数不能当实测。** 提示词拟采用 A 50mm F2.0、B/C 35mm F2.8；V1.1 Blender 实测机位使用 22/24/35mm。新焦段、景深和近门设备空间未经同场景验证，不能宣称一致或以百分比代替画面检查。
4. **时长与试听。** 现有提示词约18秒；曾提出约17秒试剪作为建议，未被用户明确批准，不能把建议写成现行定稿。五句合成语音分别约1.99、2.26、1.82、4.60、3.79秒；这是占位，不代表正式口语与喘息可压缩到同样长度。
5. **下镜与声音应分时间和画面。** 用户希望跳过妻子拿衣服的过程、下一镜直接见她拿换洗衣服从房间出来。V4.3 已写出时间省略后的椅子移动、脚步、阳台衣架及取衣声，独立文本见[下一镜声音衔接](prompt/下一镜_声音衔接提示词.txt)。它不属于 C02 丈夫仍坐着的18秒画面，需下一段或后期实现；没有生成或试听该声音桥。阳台无门，不加阳台开关门声；关键经过沙发是否接触不可展示或由音效断言。
6. **剧本版本差异需同步，不暗改。** GitHub 现行 V1.6.6b 仍为旧五句对白及“离开书房进入卧室拿衣服”；本轮用户已确认 C02 打游戏空间就是卧室，并改用上述五句。本交接只登记新指令与差异，未改文学剧本；妻子在同一房间内取衣后出来的具体机位和空间接口待导演核准。

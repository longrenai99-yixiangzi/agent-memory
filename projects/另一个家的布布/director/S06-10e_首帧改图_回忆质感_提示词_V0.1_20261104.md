# S06-10e 首帧改图：回忆质感 V0.1

用法：原首帧（岛台首帧图）作 @图片1 做图生图/改图；可再附妻子五官 @图片2、布布三视图 @图片3 帮助保脸。4K 宽输出，16:9。

## 改图提示词（整段复制）
```text
在@图片1的基础上做改图：构图、人物位置、姿势、衣服、道具、桌面物品全部保持不变，只改画面质感和光线，并微调布布的头朝向。

保持不变：16:9 构图和机位；妻子坐在左边高脚凳上，身体略前倾，右手筷子夹着一小卷面，面碗在台面上冒热气；布布蹲坐在右边高脚凳上；岛台、两把凳子、窗户（无窗帘）、冰箱、橱柜、熄灭的吊灯的位置和外观；她的脸、发型、浅燕麦色针织开衫、白色内搭、浅灰长裤、粉色拖鞋；布布的毛色和外貌。台面上除一碗面外没有其他物品，没有任何猫用品，没有文字和水印。
需要微调：布布的头朝向妻子，目光落在她的脸上（不是看着碗）；耳朵朝前，身体略前倾，像要朝她跳过去。其余姿势不变。

改成回忆质感：
色调：整体偏暖，像午后蜂蜜色的阳光，白墙和白瓷带一点奶油黄，阴影偏暖棕，不偏绿不偏蓝，肤色温暖通透，饱和度适中。
胶片感：35mm 彩色负片质感（类似柯达 Vision3 250D 日光片），细腻均匀的中等强度胶片颗粒，墙面和暗部更明显；高光有柔和泛光和轻微光晕，暗部略抬、不死黑；四角轻微暗角。
光影：午后阳光从两扇窗户斜射进来，空气里有细小灰尘，形成可见的丁达尔光束（柔和的斜向光柱从窗口落向台面和地面），台面和地板上有暖色光斑；她的侧脸和布布的卷毛边缘有一圈柔和的暖色逆光轮廓光。
朦胧感：整体一层很轻的柔焦和雾化，高光带柔和泛光，背景（窗外、冰箱、墙面）略虚、边缘柔化，像被记忆磨软了；但她的脸、眼睛、手、面碗，以及布布的头、耳朵、眼睛必须清晰可辨，不糊。
情绪：一眼能看出是回忆——暖、软、亮，带一点点褪色的怀旧，但内容平静日常，不伤感。
直线不变形，不要新增任何物体，不要窗帘。
```

## 核对要点
1. 构图、人物、衣服、拖鞋、碗和凳子位置与原图一致，没有多东西；
2. 布布的头朝向她、不看碗；
3. 暖色、颗粒、光束、柔焦都有，脸和手仍清楚；
4. 光束别太浓（不能像雾霾、不能遮住她的脸）。

## 注意
- 改图模型可能把她的脸改走样：附上妻子五官 @图片2 并在提示词最前加“脸以@图片2为准”；或者生成多张挑最像的。
- 改好的这张替换 Seedance V0.7 里的 @图片1（首帧），Seedance 提示词【五】里的质感段可保留，只是此时会更稳。
- 色调是回忆专用，不并入全片统一的日间图，避免影响日间图的统一色调。

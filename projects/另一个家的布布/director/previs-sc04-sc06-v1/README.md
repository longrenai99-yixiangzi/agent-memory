## 已取得的证据与结论

1. **输入版本明确：** 新VIEW-03已由用户指定替换，GitHub提交f0ed3f2的原字节大小/SHA-256核验通过；旧版及首次8图回执保留历史。预演记录绑定新版哈希。
2. **阳台通路可作为当前候选：** VIEW-01与新版VIEW-03显示室内开放垭口，关闭的是外围窗；PLAN-001图面线条不能直接解释为必须穿越的一扇关闭玻璃门。本轮路线不打开外窗、不穿玻璃。实际开口净宽仍未实测。
3. **拓扑和点位自检：** A、退步、放猫标记在候选G内；B的搜寻/抱回标记在G外；猫X结束点在G外；7个机位点没有落在近似家具平面占地内。检查对象是点，不代表人体/摄影设备包络尺寸或净距已合格。
4. **不能根据平面图宣称通过：** 高度遮挡、焦距和实际视锥、猫的跳跃、手托猫以及所有前后轴线。图上的扇形仅表达朝向，不是已算出的镜头视场。
5. **已接受的空间差异不强制返工：** 正式平面与侧视的茶几颜色等差异保留；本轮只核相对空间。首尾帧制作时对同一连续段选定同一茶几外观，提交用户确认，不静默改母版。

## 需要导演确认的三项具体问题

### 1. 认可本图路线作为下一轮关键帧依据吗？

推荐：A原位守候/抱猫/放手，B在G外侧移，猫沿本图E—沙发—茶几—A—X路线；机位按图中固定候选继续做视角帧验证。优点是空间因果可追溯、演员不追猫穿窄缝；风险是跳跃和低位遮挡仍需试帧。备选是调整G内猫的绕行线/机位，保持所有已确认剧情节点与边界不变，待首轮关键帧显示具体障碍后再比较。路线建议不是最终分镜定稿。

### 2. SC04到SC05的重复下蹲如何衔接？

正式剧本23:15写“慢慢蹲下”，23:21接触猫时又写“慢慢蹲下来”；23:23抱猫后，SC06写A站立。未交代中间起身，不应在生成时让模型自行补。

- 推荐：23:15降低重心并蹲稳，保持观察；23:21沿同一低姿伸手，23:23托猫后明确一次抱稳起身，接SC06站姿。视觉上连贯、避免重复起蹲；风险是长时间蹲姿/裙摆连续性需统一，表演停留须由导演认可。
- 备选：23:15先蹲下，观察时明确起身，23:21再蹲下接触。保留两个完整蹲下，但多一次起身与剪辑接口，容易分散重逢节奏，也增加生成风险。

本轮图只画地面位置，不擅自选择或修改剧本姿态。

### 3. 客观双妻子与B主观是否按C61→C62验证？

推荐：客观镜头建立位置，接B真实眼位空镜，观众通过同一家具识别“看不见”。备选为A过肩观察B、B主观空镜、A反应的三段覆盖；后者减少单镜双人身份冲突，但增加剪辑且同框关系较弱。两种方案都不允许把B主观画成G内家具消失，也不改变B不知情。

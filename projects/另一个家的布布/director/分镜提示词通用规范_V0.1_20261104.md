# 分镜提示词通用规范 V0.1（适用于所有镜头）

> 日期：2026-11-04。来源：导演 2026-11-04 的要求，并与导演分镜 skill（连续性基准 + P1…Pn）一致。  
> 作用：之后每个镜头、每个任务的模型执行提示词都按这份写；写完逐条对一遍。

## 1. 每条提示词必须包含的六块

| 块 | 写什么 |
|---|---|
| **① 参考素材** | 逐张列出上传顺序（@图片1…），每张写**职责**，并写明**优先关系**（见第 2 节） |
| **② 每个镜头** | 逐镜写：景别、机位、人物位置、画幅，加下面第 3 节的摄影意图参数 |
| **③ 动作与情绪** | 情绪必须落到**动作 + 面部表情 + 眼睛**（见第 4 节），不能只有抽象的情绪词 |
| **④ 时间与声音** | 剧情时间（含钟面读数）、雨势、环境声、画内对白（逐字）、画外声、不加的声音 |
| **⑤ 色彩与空间** | 色调基准（统一夜景/白天/监控）、光源来源、家具和人物相对位置、不许动的东西 |
| **⑥ 连续性与禁止** | 跨镜不变的项（身份、服装、鞋、道具状态、钟读数）；明确不要的东西 |

## 2. 参考素材的职责与优先关系

| 素材类型 | 管什么 | **不管什么** | 优先级 |
|---|---|---|---|
| **人物五官图** | 面部、发型的身份 | 服装、背景、固定表情 | 面部以它为准，高于一切其他图 |
| **服装图（三视图）** | 衣服、鞋、体态 | 脸 | 服装以它为准；脸不被它覆盖 |
| **场景图** | 房间结构、家具位置与外观、光色 | 人物、构图角度 | 空间以它为准；构图图不能改变它 |
| **构图图**（机位参考） | 摄影关系：从哪边看、景别、人物与背景的相对位置 | 人物身份、场景细节 | 只定“怎么拍”；与场景图冲突时，场景图为准 |
| **光色/气氛图** | 冷暖关系、阴影层次 | 家具、几何、人物 | 最低，只作气氛 |
| **道具/状态图**（挂钟、毯子、相框等） | 外观 | 摆放位置、读数 | 外观以它为准；**位置和读数以镜头写明为准** |

提示词里要把这几条用一句话写进“参考素材”块：例如“面部以@图片1为准；服装以@图片2为准；房间以@图片5为准；@图片6只定摄影关系，不覆盖房间与人物；@图片7只作冷暖气氛”。

## 3. 摄影意图参数（标为“摄影意图”，不冒充实测值）

每个镜头保留并写出：**景别、焦段、光圈、机高、人物位置、画幅比例、焦点、前景遮挡控制**。

格式示例：

> 摄影意图（非实测）：中近景，约 35mm、F2.8，机高约 1.46 米，16:9。焦点在丈夫脸上，妻子左肩作前景，约占画面宽度 10%—20%，略虚、不遮脸。

规则：
- 所有参数后面带“约”，整条标“摄影意图（非实测）”；Blender 或实拍测过的，才标“已测”并写数值来源。
- 前景遮挡写清：谁、占多大、虚不虚、不许遮哪里。
- 画幅比例每条都写（默认 16:9）。

## 4. 情绪必须落到动作与表情

**不允许**：只写“她很难过”“丈夫很错愕”“神情复杂”。
**要写**：先后顺序的**动作**（手、肩、呼吸、脚）、**面部表情**（眉、眼睑、嘴角、嘴唇）、**视线去向**（眼睛的任务），再写**结束状态**。

写法模板：

> 〔情绪标签，仅作导演备注〕→ 可见动作（按先后）：…；面部：眉…眼睑…嘴角…；眼睛：先看…再看…；结束时：…

示例（不是抽象的）：
- 反例：丈夫错愕。
- 正例：丈夫鼠标上的手停住；眉毛抬高半寸；眼睛睁大，眨一下；嘴唇微张又合上；视线从屏幕移到门口，停在妻子脸上。

SC 内已有的“反应镜头行为表”（可见行为、眼睛任务、结束状态）直接复制进提示词，不再改写成情绪词。

## 5. 时间与声音

- 写剧情时间；钟入画时按《挂钟读数表与指针描述》写指针位置，并写“不要使用参考图里 10:10 的指针位置”。
- 雨势：细雨 / 更大 / 雷暴 / 雨停，与雨线对应。
- 声音：环境声床（雨声）、画内对白逐字、画外声、不加的声音（如“无配乐”“无开关门声”）。
- 对白：逐字保留，一个镜头一个说话人。

## 6. 提示词写完后的自查清单

- [ ] 六块都有；
- [ ] 每张参考图有职责和优先关系；
- [ ] 每个镜头有摄影意图参数，且标了“非实测”；
- [ ] 没有只写情绪词的段落；
- [ ] 钟读数、雨势、服装、鞋、毯子状态都写明；
- [ ] H01–H06 对过；
- [ ] 对白逐字，未改字；
- [ ] 夜景色调统一基准写进“色彩与空间”。

## 7. 运镜与切换技巧（导演 2026-11-04 要求，对所有镜头适用）

原则：**每个运动都要有动机**（她在看什么，心理在紧还是松），一个镜头一个运动，运动要写**总行程和时间**，并标“摄影意图（非实测）”。导演使用 Seedance 2.5，按它能准确执行的前提把运镜写清楚；第一轮生成后按实际效果再调。

| 想表达 | 技巧 | 写法要点 |
|---|---|---|
| 紧张逐渐增加 | 景别逐步收紧、切点加快、极缓推进 | 写每一步的景别和推进行程、时间 |
| 异常被发现 | 焦点转移（rack focus） | 写“先对焦 X，约 N 秒内移向 Y” |
| 心理转折 | 镜头完全不动（前面一直在动），或甩镜 | 静止要写“机位锁死”；甩镜写时间和动态模糊 |
| 贴近角色 | 低机位跟走、随人下降 | 写机高、行程、时间、跟随谁 |
| 认知的瞬间 | 希区柯克变焦 | Blender 白模渲染，不走 AI |
| 先闻其声 | J 切（声音先入） | 写声音比画面早多少 |
| 时间流逝 | 钟读数、雨势变化 | 见《挂钟读数表》 |

**限制：** 凡带 A/B 两世界重影的镜头，A 版、B 版要同机位分别出再叠加，运镜必须一致，所以这类镜头保持固定机位，只用焦点转移和剪辑表达；只有单世界的镜头可以运动。

每场过稿时，除 H01–H06 外，再对一遍：这一场有没有可以用运镜或切换帮助表达情绪或剧情的地方。

## 8. 借助 skill 核对后的写法规则（2026-11-04，来自 seedance-shot-design、higgsfield-camera、shot-recipes）

### 8.1 Seedance 安全写法（中文提示词用中文运镜词）
裸写的英文运镜词（Dolly、Crane、Aerial 等）可能被审核误判。中文提示词用：缓慢推进、缓慢拉出、固定镜头、水平摇摄、横向平移、推轨推进、摇臂升降、升降平移（机身垂直升降、不改俯仰角，跟随人起立/坐下）、跟踪镜头、焦点转换（缓焦转移 / 急焦切换 / 呼吸焦点）、希区柯克变焦、甩镜转场。

### 8.2 运动写法
- **写总行程和时间**（微小运动尤其要写，否则模型会夸大）；写“慢到几乎察觉不到”。
- **运动要能产生所写的终止构图**：缓慢推进不可能从全景推到大特写；10 厘米的拉出不可能完成全身揭示。运动和终止构图不一致，提示词内部就不成立。
- **运动强度词与运镜节奏一致**：轻柔、缓缓、渐渐，不要“缓慢爆裂”这类矛盾组合；每个动作都带强度词（如“缓缓”“猛然”“稳步”）。
- **一个镜头一个主要运动**；运动要分阶段写时间（例如“0–3 秒…，3–6 秒…”）。
- **摇镜与滑移要分清**：“镜头位置不动，水平摇摄跟随”与“镜头与人并行滑移”不是一回事，要写明是哪个。
- **特写和插入镜头**加焦点锁定句：“焦点始终锁定在 X 上，从第一帧到最后一帧不漂移、不拉焦”；广角或快速镜头加“直线不变形，无桶形畸变”。

### 8.3 镜头与情绪的对应（higgsfield-camera 的“镜头是角色情绪的替身”）
| 角色情绪 | 镜头写法 |
|---|---|
| 震惊/揭示 | 固定 + 极缓推进或拉出；揭示的瞬间“冻住”，之后 0.5–2 秒几乎不动 |
| 悲伤/脆弱 | 手持、缓慢、低机位、略向下缓移 |
| 平静/克制 | 平稳、轻微呼吸感 |
| 需要空间（崩溃后） | 缓慢从中近景拉到全景，“把人物留给她自己” |

### 8.4 表情写法（seedance-shot-design 的微表情规则）
- **四个陷阱**：完美对称、情绪瞬间切换、夸张卡通、面瘫静态。对策：写**单侧**动作（“左侧嘴角先……”）；写**渐进**（“缓缓/一点点”，留 1–2 秒过渡）；用克制词（“微微/轻轻/不易察觉地”）；加**呼吸起伏和偶尔眨眼**。
- **禁用词**：极度悲伤/愤怒/恐惧、突然大哭/大笑、“脸上露出××的表情”、表情丰富。要换成具体的面部动作。
- **强度默认 L2（内敛可读）**；铺垫用 L1；L3 只在高潮；递进 L1→L2→L3，不跳级。
- **一个切片 = 一个核心变化 + 一个联动细节**（眼神变化时呼吸也变）。
- **景别决定可写的细节**：中景只写整体情绪和手、身体、重心；中近景写 1–2 个面部区域；特写才写 2–3 个区域。

### 8.5 配方卡（shot-recipes）可直接套用的
| 配方 | 用在哪 | 要点 |
|---|---|---|
| **变焦点揭示** | S04-07、S02-06～07、S02-11 | 机位固定、只放**两层景深**（前景一件、背景一件，两层都点名）、浅景深写死、约 3 秒；前景要写成具体实体，不然糊成一块墙 |
| **甩镜过桥** | S04-11 | **两格都要写运动模糊**，甩动方向两格一致，模糊只在第 1 格尾部和第 2 格头部各半秒左右；背景要有竖向线条（柜腿、门框） |
| **缓推面部** | S03-10 | 极缓推进到脸，行程写清楚 |
| **反应静持** | 各反应镜头 | 反应后停住，不急着切 |
| **定格** | S03-05 | 定格 2 秒 |
| **门槛跨越** | SC06 出入 G 的边界 | 两侧内容逐项点名，边界写死 |

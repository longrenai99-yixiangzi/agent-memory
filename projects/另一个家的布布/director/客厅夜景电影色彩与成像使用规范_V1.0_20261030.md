# 《另一个家的布布》客厅夜景电影色彩与成像使用规范 V1.0

> 更新：2026-10-30｜范围：客厅夜景（阳台方向、电视墙方向）及后续镜头色彩制作流程  
> 状态：**制作流程规范已整理；C6 调亮版为用户同意的临时电影视觉参考，尚非最终电影调色定版、最终 LUT 或全场景统一验收。**  
> 权威顺序：**现行剧本 V1.6.6b / 已批准空间与镜头依据 ＞ 原始中性场景母版 ＞ C6 临时电影参考帧 ＞ 六色示意色卡及文字风格规范**。任何色彩或成像参考不得修改已核定的几何空间、机位或陈设。

## 0. 本规范解决什么问题

本项目的客厅、餐厨、游戏卧室和其他场景需要从“空间资产”与“电影视觉效果”两条独立流程制作：

1. **中性场景母版**：用于确认空间、家具、自然材质色、基础曝光和一致性；不得预先烘焙强烈的风格滤镜、重颗粒与夸张光晕。
2. **镜头级电影光影版本**：根据剧情、摄影机、人物站位、原有光源和环境条件做主光/负补光/明暗取舍；可以为首帧或视频提供视觉指导。
3. **最终成片调色与成像层**：统一镜头白平衡、曝光、对比度、肤色、冷暖关系，再叠加适度的光学柔化、泛光、光晕及细颗粒。

**色卡不是滤镜，不是 LUT，也不能凭六个 HEX 直接把两支视频自动调成一致。** 色卡负责方向；参考帧负责整体亮度、光影和区域分布；可复用的调色节点/参数负责最终执行。

### 1.1 场景连续性硬约束

- 原始摄影机机位、取景、画幅、透视与所有已批准物件必须保持。**只调色/布光时不得重构空间**。
- A 世界现有沙发、茶几、电视柜、窗/阳台、门、植物及其他陈设以已批准原始资产为权威；不自行添加地毯、边几、灯具、装饰。
- 阳台晾晒衣物、洗衣机位置及可见范围以每一机位的原图为准，不可因为“更有电影感”而移动或删减。
- 电视墙方向与阳台方向各有真实的光照差异；不要求画面平均亮度、蓝色面积完全相同，但同一材质应保持可信的颜色连续性。
- 任何 AI 重绘版本出现新增物件、改变相框方向/内容、不同柜门状态或移动家具时，**光影表现即使漂亮也不能替代母版**。

## 2. 客厅夜景视觉目标

**关键词：自然主义低调摄影、克制冷暖分离、深而有细节的阴影、柔和高光过渡、微弱胶片肌理。**  
不是亮橙/深蓝的模板滤镜，不是全场景同一色温，不是单纯压黑画面。

### 2.1 色彩构成与用途（当前视觉设计参考）

| 参考色 HEX | 名称 | 主要用途 | 避免 |
|---|---|---|---|
| `#AF8B73` | 暖米白 | 沙发/布料受光部分的暖中性色 | 把沙发整体染粉、染橙 |
| `#A68457` | 柔和琥珀 | 室内已有灯具的局部暖光 | 大面积无来源黄光 |
| `#5A5343` | 灰绿暗调 | 低照度墙面、中间调与暗部过渡 | 墙面被做成脏棕色 |
| `#713E22` | 深木棕 | 木制家具受光后的深色层次 | 木柜整体过度红橙 |
| `#062D4A` | 深夜蓝 | 窗外夜色、临窗少量冷色反射 | 蓝光蔓延整间客厅 |
| `#261B14` | 暖黑 | 室内深阴影与局部低调区域 | 死黑与完全丢失细节 |

> **证据说明：** 这些 HEX 来自前期视觉讨论的**近似目标色示意**，不是对 C6 调亮版逐区域精确取样、也不是实拍色卡测色结果。若后续从批准的原始文件重新采样，应生成独立的“实测色卡 Vx”，不得悄悄覆盖这组设计参考值。

- 推荐的概念性视觉权重：低饱和中性材质约 65%、冷色环境约 20%、局部暖光约 15%。**只用于描述主次关系，不是像素硬指标**，不同镜头可大幅变化。
- 白色瓷砖、米白布艺、浅绿墙面、自然原木是不同的“固有色”；室内外光源引发的颜色变化应在局部、遵循衰减。
- C6 调亮版选定的亮度方向为**有夜景深度但能辨别沙发、家具和地面细节**；不能再按此前偏暗候选机械压黑全图。

## 3. 三个可独立审核的制作控制层

### 3.1 A 层：布光与明暗结构（Lighting）

**输入：** 中性/结构权威母版、夜景环境依据、现有灯具位置与人物/摄影机站位。  
**操作：** 确认光从哪里来（现有灯具、窗外弱冷环境光）；控制每个光源的作用范围与衰减；减少无来源的均匀填充光；允许次要墙面与角落沉入有细节的暗部；地砖保留真实反射但限制过亮的展示性反光。  
**验收：** 灯位不变、没有新光斑/新增灯具；冷暖来源可解释；沙发、茶几、人物预计落脚区域的受光合理；阴影不死黑；两机位明暗逻辑一致。

### 3.2 B 层：材质与真实度（Material）

**输入：** A 层结果与已确认材质。  
**操作：** 维护布艺细纤维、缝线与褶皱；木材细木纹与柔和高光；瓷砖原有反射与接缝；玻璃/窗户的适度反射。仅进行真实存在细节的微对比控制，不凭空添加粗糙纹理、脏污或旧化。  
**验收：** 材质类别与纹理连续性不变；沙发不能塑料化、木材不能过度锐化、地砖不能变成不符合原资产的哑光粗石材。

### 3.3 C 层：镜头光学与最终成像（Optical Finish）

| 效果 | 当前目标强度 | 使用位置与边界 |
|---|---|---|
| Highlight Roll-off 高光过渡 | 中度优化 | 已存在的灯光高亮、窗边与地砖反射；保留细节，不制造大白斑 |
| Bloom 泛光 | 弱～中弱 | 只在现有足够亮的实光源及亮部边缘自然扩散 |
| Halation 高光晕光 | 弱 | 高反差暖光边缘极轻微暖色晕染；不把整片墙染橙 |
| Lens Flare / Veiling Flare | 关闭或极弱 | 没有明显直射镜头强光时不人为生成条纹或鬼影 |
| Lens Softness | 极轻微 | 抑制数码硬锐，保持关键物件与人脸细节 |
| Film Grain | 极细、低强度 | 优先在最终视频后期施加，避免 AI 运动时颗粒闪烁 |
| Vignette 暗角 | 极弱 | 不出现可察觉的黑边、假聚光 |

**验收：** 依次对比“布光前/后”“材质层前/后”“成像层前/后”；任何一层不能以画面整体变糊、假雾气、颗粒变脏换取“电影感”。

## 4. 什么时候用、如何用：六阶段执行表

| 阶段 | 主要输入 | 必须做 | 暂时不做 |
|---|---|---|---|
| ① 场景资产制作 | CAD / 彩平图 / Blender / 已批正视图 | 核对建筑、家具、材质、机位；保存**中性母版** | 不烘焙完整 C6 电影滤镜 |
| ② 镜头与人物设计 | 剧本、导演设计、站位与镜头轴线 | 根据人物情绪/运动与真实灯位设计主光、负补光和暗部 | 不凭单张图反向猜测空间 |
| ③ 电影首帧 | **A：中性原图** + **B：C6 临时参考帧** + **C：六色色卡** | A 锁空间，B 只看光影/成像，C 只看色彩关系；按层审核 | 不让风格参考覆盖原场景 |
| ④ AI 视频草稿与正式生成 | 已核准的电影首帧 + 动作/机位提示词 | 480P 草稿重动作/运镜/光源连续性；正式分辨率再核色彩与细节 | 不把 HEX 色卡当场景物件；避免烘焙重颗粒、强光晕 |
| ⑤ 视频后期镜头匹配 | 正式视频 + C6 目标参考静帧 | 先统一输入色彩管理，再逐镜头校曝光、白平衡、肤色、对比与冷暖 | 不直接套同一 LUT 便宣称已一致 |
| ⑥ 最终影像完成 | 已匹配镜头 + 成像预设 | 控制细颗粒、Bloom、Halation、高光过渡、轻微柔化，检查动态稳定性和输出 | 不用夸张 Flare/暗角掩饰光影问题 |

**在 Seedance / H3 中：** 优先用批准的电影化首帧做主参考；只有平台明确支持“风格/调色参考”的独立输入时才单独传色卡，否则将六色关系概括成文字，避免误识别成画面里的卡片或分散动作控制。对模型已经生成的视频，最终颗粒与光晕应尽量后期统一，减少跨帧闪烁。

## 5. 图像生成提示词：分层约束模板（用于已锁机位）

**【参考职责】**  
参考 A：唯一场景与摄影机母版——机位、景别、画幅、门窗、家具、摆件、灯具与阳台晾晒物的数量和位置保持不变。  
参考 B：C6 调亮版——仅参考电影化亮度、冷暖光、空间明暗、细腻的成像质感。  
参考 C：六色色卡——仅用于主辅色和颜色区域关系，不作为画面中出现的物体。

**【机位与空间】**  
使用参考 A 的原始相机方向和光学透视；不得新增地毯、边几、壁画、前景遮挡、灯具或其他装饰；不得移动或删除原家具，不得改变相框内部图像、朝向、尺寸与位置。

**【布光 A 层】**  
保留现有室内灯具位置及其暖色局部照明；光线按真实距离衰减。窗外深蓝夜景带入微弱冷环境光，仅影响临窗区域；大面积墙面与角落允许柔和沉暗。沙发与茶几保留适度受光，地砖保留已有反射但不过亮。不得创造无来源的侧光、聚光或透过不存在窗户的亮斑。

**【材质 B 层】**  
沙发布料有自然纤维、缝线与褶皱，木柜有细腻木纹，瓷砖保留真实反射及材质光泽；不添加磨损、污渍、纹理重绘，不改变真实颜色类别。

**【成像 C 层】**  
自然高光滚降，轻微 Bloom 和暖光边缘 Halation，少量镜头柔化，低饱和冷暖分离。不得强 Flare、HDR 锐化、夸张暗角、雾化或粗颗粒；精细统一 Film Grain 留给成片后期。

**【验收】**  
拍摄方向、画幅、家具、门窗、原图物件全数保留；重点核对现有灯光来源、颜色职责、材质真实度和高光/暗部表现。若空间或物件发生变化则本轮失败，不能作为母版替换。

> **适用范围：** 已批准同一场景的光影/质感修改。**反向机位、跨房间运动或复杂透视**必须先用真实平面图或 Blender 预演确定空间，不应单靠“反向视角重构”文字强行生成。

## 6. DaVinci Resolve 后期使用办法

1. **输入与输出色彩管理**：确认源视频实际色彩空间、Gamma 与交付标准，避免重复套技术转换。8-bit/已有重压缩素材不保证可以大幅恢复死黑和过曝。
2. **基础镜头平衡**：每个镜头单独调曝光、色温/白平衡、对比、饱和度；结合示波器检查黑位、高光与肤色，不机械追求平均亮度相同。
3. **参考帧比较**：使用 Gallery Still 或参考画面对照 C6 调亮版的整体亮度/冷暖/区域受光；色卡辅助判断六类目标色的用途。
4. **创意风格层**：将通过验收的色彩转换或共享节点作为统一风格层；根据机位和人物肤色逐镜头局部修正。
5. **光学完成层**：在镜头匹配后施加微量 Bloom、Halation、Lens Softness 和一致的 Film Grain；检查连贯镜头有无颗粒闪烁、光晕跳变、暗部压死或窗外丢层次。
6. **保存与回滚**：保留原始无风格版本、镜头匹配版、创意风格版和成片输出版；已通过的节点树可再整理 LUT，但**当前六色色卡本身不是 LUT，也没有已验证的正式 LUT 文件**。

## 7. 各剧情段落如何继承、哪些情况不适用

| 剧情/场景 | 继承什么 | 允许哪些变化 |
|---|---|---|
| SC01 普通夜景 | C6 临时基准的真实中性材质、克制暖光、弱冷夜景与细腻成像 | 根据人物站位与实际灯具调整局部受光 |
| 第一夜轻微异常 | 中性色/成像原则 | 局部冷暖与阴影可轻微变化，避免过度惊悚 |
| 第二夜异常递进 | 摄影质感和真实光源原则 | 适度增强光比、深蓝环境与心理性暗部 |
| 第三夜强交汇 | 一致的材质/摄影系统 | 按剧情条件设计局部光影冲突，不能凭空开灯或改空间 |
| 尾声 | 同一套整体成像语言 | 依据情绪和时段设计新的光量与色温，不机械复用强悬疑色调 |
| 游戏卧室夜景 | 相同的中性化/成像原则 | 显示器蓝光、机箱 RGB 与桌面 LED 应按此场景真实光源另定 |
| 白天、白模、空间审核 | 几何/材质核验流程 | **不套用**客厅夜景完整色彩与光学效果 |

剧情的天气、交汇时间窗口、A/B 世界可见性与镜头机位仍服从现行剧本及原审批，不得因为色调方案自创异常灯光或改变剧情发生时间。

## 8. 命名、验收与下一步

**推荐版本命名（仅作为未来命名规则）：**

- `LivingRoom_Neutral_<View>_Vx`：原始/中性场景（长期保留）。
- `LivingRoom_NightLighting_<View>_Cx`：镜头级灯光预览。
- `LivingRoom_Cinematic_<View>_Cx`：电影视觉候选。
- `LivingRoom_FinalGrade_<Shot>_Vx`：通过镜头级后期验收的成片调色。

**验收顺序：** ① 空间/机位与全部物件是否未变；② 光源是否合理；③ 墙面/沙发/原木/地砖材质是否可信；④ 窗外蓝与室内暖是否不过度污染；⑤ 暗部细节和高光是否稳定；⑥ 细颗粒/泛光是否克制；⑦ 连续镜头切换是否跳色、跳光。

**待办（未完成，不能写成已验收）：**

- 在原始两机位素材上复核 C6 调亮版的真实空间一致性，排除 AI 重绘变化。
- 用同一影片色彩方向制作电视墙方向候选，在同场景两机位之间做色彩/光源连续性检验。
- 在实际有人物的镜头验证肤色、眼神光、面部阴影与空间明暗。
- 等正式视频素材生成后，利用 DaVinci Resolve 建立可复用的节点预设，再考虑经验证的 LUT 与胶片颗粒统一标准。
- 若需要可直接通过 GitHub 获取 PNG、参考对比或 LUT，应在**另一次媒体资产上传、SHA-256 及引用核验**后补充入库登记。

---
**执行结论：** 不用色卡反复重绘场景。先把结构中性母版和拍摄机位固定，再用 C6 调亮版引导电影首帧的布光与成像，最终以实际镜头为单位做后期匹配与统一 finishing。

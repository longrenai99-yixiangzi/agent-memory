# 《另一个家的布布》灯光状态与逐字复用的光线描述 V0.1

> 日期：2026-11-03  
> 状态：**草稿，待导演确认**。依据：Codex 灯光状态（NIGHT_NORMAL、DAY_NATURAL、NIGHT_MONITOR、STORM_OVERLAP、MORNING）、V1.1 夜景基准与 V1.0 使用规范、你今天确认的三条（新参考组、对比拉大、墙面偏橄榄）、cinematic-director 的“不变量逐字复用”。  
> 用法：**每个镜头的提示词里，把对应状态的那一句光线描述原样复制进去，不改字**。逐字相同是防止同一个状态在不同镜头里“重新理解”光线。

## 1. 全片通用的光线禁令（每个状态都适用）

- **每处明显的亮斑、反光都要能指认到具体灯具或窗光**，不加无来源的光斑、侧光、体积光。
- **补灯不等于抬高整体曝光**；整体亮度不得高于该状态的标准图。
- 电视关闭时是暗色反射体，**不向房间发射屏幕蓝光**。
- 色彩只用于“方向”，不当 LUT；最终调色在后期统一。
- 不用极暗档位：日常客厅全景里的陈设、材质和人物位置必须能辨认。

## 3. 逐字复用的光线描述

### NIGHT_NORMAL

```
夜晚，细雨。窗外是深青蓝的雨夜城市灯光，只有一点冷光从阳台窗口进来；室内只有天花嵌入式射灯在墙面上形成的几处柔和的暖色光斑，光斑边缘柔和、有衰减；墙面是压低的橄榄灰绿，沙发米白，木家具低饱和；暗部很深但家具仍然可以辨认，地砖有来自窗光和射灯的真实反光；不新增任何光源。
```

### DAY_NATURAL

```
白天，阳光透过阳台玻璃从一侧斜射进客厅，明亮、自然、中性，不偏暖；室内灯全部关闭；墙面橄榄灰绿，沙发米白，地砖有明亮的窗光反射；不新增任何光源。
```

### NIGHT_MONITOR

```
家用监控的夜视画面：固定在展示柜顶朝沙发的广角，红外黑白（略偏灰绿），有明显颗粒，光源泛白、边缘发散，角落有日期时间戳；不移动任何灯位，不出现彩色。
```

### STORM_OVERLAP

```
雷暴夜。窗外雨更大、更冷更暗，偶尔的闪电只让玻璃和窗边瞬间变亮，不让室内持续变亮；室内射灯的位置和暖色光斑与平时夜景完全一致；A、B 两个世界的外围叠合时使用同一套光，B 世界不更蓝也不更黑；不新增任何光源。
```

### MORNING

```
雨停后的清晨，柔和的自然晨光从阳台一侧斜射进来，玻璃上有残留的水珠，明亮、偏中性微冷白，不过暖；室内灯全部关闭；墙面橄榄灰绿，沙发米白；不新增任何光源。
```

### STUDY_NIGHT（书房，需你确认）

```
书房夜晚：桌面台灯的暖光和显示器的冷光形成局部的暖冷对比，其余区域沉在柔和的暗部里；不是整体的蓝橙滤镜；每一处亮光都对应台灯、显示器或机箱灯。
```

### EXT_*（室外窗空镜）

- **EXT_NIGHT_DRIZZLE**（SC01、SC02 第二夜）：
  ```
  从阳台外窗的外侧朝室内拍。细雨，玻璃上有细小的水珠和缓慢下滑的水痕，玻璃上有城市灯光的模糊反光；暖色的客厅虚化在玻璃后面。
  ```
- **EXT_NIGHT_RAIN**（SC02 第三夜）：同上，但“雨明显更大，水珠更密，水痕更长”。
- **EXT_STORM**（SC03 结尾）：同上，但“雷暴，闪电照亮玻璃，雨势很大”。
- **EXT_MORNING**（SC07）：
  ```
  从阳台外窗的外侧朝室内拍。雨已停，阳光明亮，玻璃上有少量残留水珠；客厅虚化在玻璃后面。
  ```

## 4. 要你确认的

1. ✅ **已确认（你说“一起靠一点”）：白天、清晨的墙也往橄榄靠一点。** 实测：白天墙色相约 43–51°、饱和 0.21–0.28；夜景调色后约 50–56°、饱和 0.36。色相本来就接近，差别主要在亮度和饱和，所以只做了很轻的一步：白天墙色相 +4～6°（约 51→55°、47→53°），饱和不变，只作用在墙面（日照亮斑、沙发、木家具不动）。试验图 `assets_work/VIEW-03_白天_墙微偏橄榄.png`、`VIEW-01_…`，脚本 `tools/day_wall_shift.py`（参数 0.4 / 62°）。肉眼几乎看不出变化，这正是“一点”；要更明显可把强度提到 0.6、目标色相 70°。
2. **STUDY_NIGHT** 这句是我根据书房图写的，你看是否符合。
3. **MONITOR 的“略偏灰绿”**：红外监控一般是纯黑白，你想要纯黑白，还是略偏灰绿？

## 5. 没核对的地方

- 灯具的真实位置和开关状态仍未在 Blender 里核对（登记表标着“未核”）。

```
这是编辑任务，不要重新生成整张图。保持画面中所有家具的位置和形状、墙面、地砖和反光、窗外的雨夜城市灯光和雨痕、构图和机位、整体色调（窗外深青蓝，室内墙面射灯局部微暖）完全不变。不要新增任何光斑、光源、人物、文字或其他物体。只做下面这一处修改：
```

### 步骤 A：去窗帘（两版都做）

```
删除阳台开口左侧的整幅棕色窗帘和半透明纱帘，露出被它们遮住的阳台开口左侧墙面（与右侧一样的灰绿色墙面）和窗洞边缘，窗洞边缘与右侧对称。
```

### 步骤 B：去贵妃位上的小物件（两版都做）

```
删除沙发贵妃位上靠近毯子边缘的那件细长的小立式木质物件，贵妃位坐垫恢复为平整的米色布面；毯子的位置、形状和褶皱保持不变。
```

### 步骤 C：加挂钟（两版都做）

```
在左侧灰绿色墙面上，沙发靠背正上方、位于墙面高处（约在天花板往下三分之一墙高的位置），增加一只圆形挂钟：浅木色圆框，白色表盘，黑色细指针，指针停在 10 点 10 分，直径约占画面高度的 7%。挂钟被墙面的射灯光自然照亮，不产生新的光源，不被沙发和抱枕遮挡，与墙面平行，不歪斜。
```

## 4. 提示

- **顺序**：A、B、C、D 做完存 SC01 版，再从它做 E 得到 SC02–SC07 版。这样两版只差衣服，别的地方完全一致。

- 改完如果发软，你再高清化；最终参考图宽度建议 2400 以上，4K 更好。

## 6. 后期合成的备选（更稳）

挂钟和相框里的照片，**钟面时间和照片内容都需要精确**，AI 编辑容易变形。如果几次都改不好：
- 挂钟：单独出一张挂钟单品图（白底，浅木圆框，白盘黑针），在 Photoshop 里贴到左墙，加一点阴影和轻微的射灯高光。
- 相框：把 `合照.png` 用透视变换贴进相框，调暗到与画面一致。

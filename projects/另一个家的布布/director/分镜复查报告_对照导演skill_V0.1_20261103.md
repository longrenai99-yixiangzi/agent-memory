## 2. 这些 skill 和我们已做的东西，各在哪一层

仓库的工作体系把文件分成三层：

| 层级 | 内容 | 我们已有的 | 对应的 skill |
|---|---|---|---|
| **① 导演真源** | 戏剧目的、空间真值、表演节拍、镜头与运镜、光源、声音、接口、批准状态 | **SC01–SC07 分镜讨论稿、总览、剧本草稿** | cinematic-director（设计）、higgsfield-acting（表演）、higgsfield-camera（镜头语汇） |
| **② 素材绑定与镜头验证** | 白模坐标、参考图职责、首尾状态、机位预演与验收证据 | 资产登记表、预演路线、K 状态帧（多数是 Codex 做的） | blender-cinematic-modeling |
| **③ 模型执行稿** | 可直接粘贴的 Seedance/H3 提示词，含参考绑定与参数 | **还没有** | **director-storyboard**、seedance-shot-design、h3-prompt-writing |

**所以你的 director-storyboard skill 和我们做的东西"不在同一层"**：我们做的是第①层，决定拍什么、为什么这样拍；这个 skill 是第③层，把**一场戏的剧本加一张场景图**翻译成 P1、P2、P3……逐镜提示词。它自己也写明：不扩写心理解释、不擅自增加动作和运镜，只执行导演已定的设计。所以顺序是：设计（我们已做）→ 这个 skill 出提示词 → 生成。

## 4. 这几个 skill 提醒我们的“该做的方法”

1. **每场写完设计，再用 director-storyboard 出 P1…Pn 提示词。** 一张场景图就能开始；人物图不是必需。
2. **两人对话一个镜头一个说话人**（cinematic-director Mode H）：SC03 的夫妻对白、SC06 的两位妻子要分镜头，或在多人镜头里严格标注谁说。
3. **同一镜头三次失败就换镜头，不是改提示词**：更短、更近、更简单、拆成两个，或移出画外只拍结果。
4. **先看全片、再批量生成**：仓库规则要求全片预演初剪通过前，原则上不开展正式视频生成。

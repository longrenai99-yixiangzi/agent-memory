## 1. 核心导演意图与本轮决策

故事不是恐怖调查：妻子发现刚整理过的毛毯出现褶皱，首先自然地怀疑丈夫弄乱了，带有**疑惑为主、轻微生活化不满**。她原本想顺手抚平毛毯，但触摸后感到布面仍有余温，于是原本连贯的整理动作被打断。她开始想到丈夫，转头看向书房。**“想抚平 → 接触 → 察觉余温 → 不再抚平 → 眼睛先向书房转 → 头部随后跟随”**，是这场戏的核心可见行动链。

用户已明确采用 **B＋A 两台独立固定机位**，取消旧版“前方倒退领拍”“后方持续跟拍”“完整步行纪录”和强制独立手部特写。不是为了景别递进而机械切三镜。

- **B｜走近（空间镜头）：** 毛毯在前景，妻子沿已核定路线接近沙发，交代空间与行进动机。
- **A｜触碰、停顿、转头（行动/心理镜头）：** 在同一固定画面里读清指尖碰触、手部停止、侧脸反应和视线转向。
- **C04（既有毛毯近景）→ B → A：** C04 已揭示褶皱，可省略部分行走时间，不重演 C03 对异常的首次发现。

**与旧文学剧本差异（重要）：** V1.6.6b 及旧 C07 写有“将褶皱抚平”。用户在 2026-11-01 最新明确决定：**本次 C05 只保留抚平意图，手因余温中途停住，毛毯最终仍保持褶皱**。当前 C05 执行以这项最新批准为准；文学剧本正文尚待另行统一版本，不得用旧句覆盖新动作。

| 先前 | C04 毛毯近景 | 固定局部近景 | 观众确认褶皱，允许时间省略 | 依据既有镜头 |

## 3. B 镜：最后两三步走近

### 3.1 机位与构图

- **用户指定的第一张 Blender 机位画面**：从沙发附近朝**电视墙、餐厨纵深方向**观察；贵妃位与毛毯位于画面前景。以实际 Blender 摄影机而非单张 AI 场景图作为空间权威。
- 固定摄影机，展示妻子由空间较深处沿真实通路接近毛毯；电视墙、茶几、餐厨等保持原模型透视关系。
- **只在剪辑中取用最后约两三步**；C04 插入镜头承担必要的时间省略，不能让妻子无原因瞬移，也不需要再次记录整个客厅长距离走路。
- 不得因为画面中能看到书房方向，就把妻子的真实来源改为“从书房走出”。她此前按 C03 已核定路线从**主卧**出来，实际脚点与走向须继承场景。

### 3.2 可执行表演

- 怀抱黑色换洗衣物，视线持续落在贵妃位褶皱上；自然走近，最后一步轻微减速。
- 眉眼略收、嘴角维持日常紧绷；没有恐惧、探险式蹑步或显著皱眉瞪眼。
- **切出点：** 到达沙发边，身体正在停稳／将要伸手，但还没有真正接触；切到 A 继续动作，避免两镜重复触摸。

## 4. A 镜：触碰、余温、转头

### 4.1 机位与构图

- **用户指定的第二张 Blender 机位画面**：从**沙发另一观察侧朝阳台、书柜方向**拍，毛毯位于左下前景；这是本轮 A 的候选机位，不得误用之前另外测试的朝餐厨方向 28mm 摄影机自动替换。
- 固定中景偏近；最终须把妻子放入真实接触姿态，再在实际摄影机视图验证，而不是只用空场景截图宣布锁定。
- **同框强制关系：** 妻子的侧脸／眼睛，空手从身侧伸向布面的路径，毛毯主要褶皱与指尖接触点均可辨认。毛毯不能只剩底边的一小块，手不能被身体、怀中衣物、沙发扶手遮挡。
- 不允许大面积白色竖向门框／墙体、多余白色圆头代理等抢画。先核对对象身份，可按镜头单独隐藏非必要预演代理；建筑构件禁止全局删除，任何局部可见性变更必须检查穿帮与其他镜头影响。
- 书房的实际方向由平面与 Blender 坐标确定；**不强制书房门进入 A 画面**，不能为了露门擅自镜像场景或改变建筑。最终转头的世界坐标方向须真实指向书房。

### 4.2 精确动作链（情绪必须可观察）

1. **准备抚平：** 一只手臂稳定抱住黑色换洗衣物；另一只空手向褶皱伸出，目光已落在目标布面。手的左右分配须与 B/C03 连续，不得凭镜头美观突然换手。
2. **指尖接触：** 手指先落布，手掌轻压；毛毯局部自然受压，褶皱总体保持。不做整片拖拽，也不预先抚平。
3. **余温触发停顿：** 准备顺势整理的手突然中止，指腹仍留在布面约 0.5–1 秒（节奏候选）；眼睛短暂停留在同一位置，原先轻微绷紧的眉眼／嘴部缓慢放松，疑惑加深。**不惊跳、不缩手、不夸张吸气或瞪眼**。
4. **看向书房：** 先移动视线焦点，再让头部自然跟随，肩膀／上身微转；并非突然整个人转身。镜头结束时尚未迈步离开。手可保持短暂接触或自然停在原处，须与后镜动作接口一致。

**镜头结束：** 毛毯仍有异常褶皱，妻子已看向书房但未开始跨出第一步。后续走向书房与夫妻对话交由下一个镜头，不在 A 内强行完成。

## 5. B → A 连续性与空间权威

- 只使用已确认的室内 Blender 场景、CAD/PLAN 布局、家具坐标及 C03 动线。不得为构图移动家具、改变主卧出口、虚构门洞或镜像画面。
- 从 B 末态到 A 初态：妻子脚点、身体朝向、黑衣物抱持状态、空手所在侧、毛毯在贵妃位的位置完全对应；换摄影机不等于换站位。
- B / A 观察方向可能差异较大，**必须在实际 Blender 画面中核对动作轴线、屏幕方向、视线匹配和物体遮挡**。如出现越轴或不清楚的空间跳跃，不得仅凭独立静态图宣称剪辑通过。
- 单镜头人物细微表演能否在白模中读懂有限；白模优先验物理可达性、轴线和镜头画幅，正式表演在真人首帧／AI 视频阶段再次验证。

## 6. 灯光、声音与场景物理规则

- 第一夜、自然生活悬疑。室内亮度足够辨认人物与触碰，窗外城市蓝夜、室内克制既有暖源；保持夜景规范的空间母版与电影化层次分离，不以材质重绘替代真实机位。
- 使用自然雨声、脚步声、衣物及毛毯轻微摩擦声。**不增加猫叫、惊吓音效、无源光效或恐怖音乐。**
- 毛毯使用用户最新提供的**灰棕色真实褶皱参考图**锁定材质、流苏和异常状态；该图为**中性灯光的道具母版**，不是正式调色样片。C03/C04 若采用“单条浅褶皱”，需在连续镜头内按最终选定状态统一，不自行增加大面积凌乱。
- 妻子面部当前主参考以 [current-face-reference.json](../assets/characters/current-face-reference.json) 为准（2026-10-31 已更新），**不能继续把 C41 当现行主脸**；A 世界睡衣资产负责服装／身形。现行黑衣物状态保持，不擅自变更。
- 用户当前对话中提交的 Blender 截图、预演视频和毛毯参考**不因本 Markdown 写入而自动成为 GitHub 已上传的二进制资产**。只有实际上传并核验后才可写“已入库”。

## 7. 真实场景图与视频制作次序

1. 使用用户已选定的 **B 实际 Blender 摄影机截图**，配合客厅实景母版、现行妻子脸与睡衣、毛毯及黑衣物，生成 B「靠近沙发但未触碰」真实电影静帧。
2. 使用用户已选定的 **A 实际 Blender 摄影机截图**，配合同一空间与人物/毛毯资产，生成 A「指尖轻触且动作刚刚停住」真实电影静帧；**一张静帧无法同时表现接触前与转头后的两个时间状态**，转头属于后续动态演出，必要时再独立制作尾帧。
3. 正式视频前先在 Blender 中确认 B 末态、A 接触与 A 转头三个关键帧的动作连贯性；检查墙/门框与多余代理物遮挡，再决定是否进入 AI 视频。
4. 若图像模型支持的参考数量有限，优先顺序：**机位白模截图 → 同空间实景母版 → 当前人物脸 → 毛毯状态 → 睡衣／黑衣物**；根据 A/B 所需细节调配，但各参考图职责不能互相覆盖。

## 8. 审核标准与禁止事项

**B：** 走近目标清楚、毛毯前景可读、行走简洁、人物来源与 C03 一致。  
**A：** 侧脸＋空手＋褶皱接触同框；能看清“想抚平但停手”；眼睛先转、头后跟；真实转向书房；毛毯没有被抚平。  
**整段：** C04 → B → A 不重复揭示、不多拍冗余行走、不因换摄影机造成空间跳跃；妻子没有突然识别超自然现象，丈夫是否碰过沙发仍不揭晓。

**明确取消：** 前导倒退跟拍、完整后方跟拍、强制独立手部特写、强制 Rack Focus、强迫书房门在同一画面出现、完整抚平、将既有资产/镜头未经验收标记为正式成片。

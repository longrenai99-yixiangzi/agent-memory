# 《另一个家的布布》SC01｜镜头 01–10 导演设计优化方案 V0.2

> 整理日期：2026-10-28（北京时间）  
> 文档性质：导演镜头设计工作稿；**不是机位、焦距、时长或最终剪辑定稿**。  
> 依据：本轮导演逐镜讨论及已确认的住宅空间约束；参照仓库《AI短片导演工作体系 V1.1》与 Higgsfield Acting / Pipeline 的表演、空间及镜头审核方法。  
> 范围：仅整理 **SC01 镜头 01–10 的摄影、场面调度、表演呈现、声画和剪辑方案**。不重新编写剧情与台词；未经 Blender 白模核验的机位均标为候选。

## 1. 本场的摄影原则

1. **观众跟随妻子发现异常**：先看到她的行动被打断，再顺着她的视线看到毛毯；不提前揭示毛毯变化，也不展示丈夫究竟有没有碰过沙发。
2. **不同镜头用不同手段讲故事**：毛毯状态、人物动作、夫妻空间关系、画外声音与剪辑各有职责；避免每镜都靠面部特写或机械停顿。
3. **第一次异常保持日常质感**：不加恐怖音效和刻意推进；妻子先疑惑，随后产生轻微不满；丈夫的否认是被误会后的真实反应，不演心虚。
4. **镜头设计遵守真实住宅空间**：卧室出来时妻子正面能看到沙发；去卫生间需要转身；书房到阳台的路线必经沙发附近；阳台没有门。任何摄影机位置、人物路线、家具遮挡都须以已批图纸与三维白模为准。
5. **演员行动要有任务**：手停、脚停、目光移开等不是情绪装饰，而是感知、判断、决策或拒绝的可见结果。

## 3. 逐镜导演设计

### C01｜妻子第一次整理毛毯

- **摄影机／构图**：客厅一侧固定宽景或中全景，容纳沙发、部分窗外雨景和妻子的整理行为。沙发毛毯是空间中的自然物品，不用极近特写突出。
- **动作**：先留约 1–2 秒安静客厅；妻子入画，铺平毛毯、顺手整理抱枕并确认；随后转身离开。动作流畅，不刻意演洁癖。
- **镜头结束**：妻子出画后，摄影机仍在原位短暂观察平整毛毯，不追人。总长先以此前讨论的 6–8 秒为节奏候选，待预演调整。
- **声音**：细雨与室内自然环境音，无悬疑配乐。
- **镜头理由**：让观众建立“毛毯原本平整”的视觉记忆。C07 将用同一块毛毯的第二次整理呼应，但不强求机械复制相机坐标。
- **白模检查**：毛毯的关键区域是否足以辨认；妻子离开时是否挡住沙发；窗、家具比例和空间方向是否真实。

### C02｜书房门口第一次日常对话

- **摄影机／构图**：从客厅或相邻通道朝书房拍固定双人中景。妻子靠近门口，丈夫在房间较深处，两人形成前后空间层次。
- **人物关系**：妻子顺路说话，丈夫仍然忙于游戏，**鼠标操作没有因为普通对话而特意停止**；不需要鼠标单独特写。
- **台词（按已讨论版本）**：
  - 妻：“你还不睡啊？”
  - 夫：“打完这局。”
  - 妻：“那你待会儿记得收衣服。”
  - 夫：“还没干吧？”
  - 妻：“可不是嘛，天天下雨。”
- **摄影机**：不为了每句台词机械正反打，保持日常交流的松弛。
- **镜头理由**：第一次对话，丈夫的注意力仍在游戏上；C09 第二次对话时他的手突然停下，形成同一人物行为的反差。
- **剪辑接口**：妻子离开书房门口向卧室走；可在本镜末尾提供出画动作，并与 C03 的必要性一起试剪。

### C03｜妻子走向卧室（候选过渡镜头）

- **摄影机／构图**：客厅和走廊交界附近，朝卧室出口方向的固定中景；不跟进卧室。
- **动作**：妻子离开书房门口，按真实动线进入卧室，走出画面。
- **镜头理由**：如果 C02 的构图无法交代卧室方向，此镜用来补足真实空间方位。
- **剪辑候选**：优先试一次去掉 C03、让妻子从 C02 末尾出画并通过脚步声过渡；如果观众会误判卧室位置，保留 C03。
- **注意**：省略镜头不能改变她确实进入卧室拿换洗衣服的剧情事实。

### C04｜丈夫走向阳台，保留画外空白

- **摄影机／构图**：客厅靠书房的一侧固定观察丈夫起身、离开游戏位置、朝阳台方向走。
- **剪辑重点**：丈夫接近必经的沙发区域之前，切走或利用真实存在的门框／家具遮挡；**不展示他是否坐下或碰毛毯，也不完整交代回书房路线**。
- **声音桥**：椅子与脚步声之后，画外传来阳台晾衣架、衣架轻碰和取衣服的轻微声音。阳台没有门，**不得添加阳台开关门声**。
- **人物信息**：妻子在卧室可以听见合理的收衣服动静；不必加一个专门的听觉反应特写。
- **镜头理由**：用声音和画外空间交代丈夫离开过书房，让妻子后续怀疑有依据，但观众无法判断他有无接触沙发。
- **白模检查**：真实路线上是否存在可用遮挡；若无，按原定切点处理，不为了遮挡挪家具。

### C05｜妻子察觉异常：脚步与视线

- **摄影机／构图**：厨房一侧斜拍卧室出口及通向卫生间的转身区域，固定中全景。30°–45° 只是从妻子行进方向估计的机位测试范围，**尚未测得实际坐标**。
- **入画要求**：能看清脚步／重心、上半身和头部方向；为她看向画外沙发的视线留空间。无需提前把整张沙发放进画面。
- **表演节拍**：妻子拿换洗衣服走出卧室，原本准备转去卫生间；目光扫过正面可见的沙发；行进和转身动作突然中断；头与身体微转回来，再次确认。
- **剪辑点**：不要在第一次停步时立即切；等她第二次看向沙发、目光真正落定，再切 C06。
- **镜头理由**：观众先看到动作为什么中断的疑问，然后才得到视觉答案。远景不能依赖过细的眉眼表演。
- **白模检查**：脚步和部分面部能否同框、卧室门洞有无遮挡、她转向卫生间的动线是否真实。

### C06｜毛毯的浅褶皱

- **摄影机／构图**：接近妻子真实视线高度和方向的沙发中近景，保留坐垫、扶手与毛毯的空间参照；不带妻子身体。
- **画面**：只在此前整理平整的毛毯区域出现一处轻微但可辨认的褶皱，不能乱得夸张；保持物品位置、外观及空间连续性。
- **摄影机／节奏**：固定、不推进，约 2 秒为节奏候选；以观众是否看清变化为准。
- **声音**：保持雨声及自然房间声，无突然惊吓音效。
- **镜头理由**：它负责“证实变化”，因此 C07 不需要再把同一褶皱拍成极近特写。
- **切接**：从 C05 妻子视线落定切入；C07 返回时她已经知道毛毯乱了，不能重新演一次发现。

### C07｜妻子第二次整理毛毯

- **摄影机／构图**：厨房侧向客厅略偏的固定中全景，三分之四侧面为候选方向。画面须容纳她从原有站位走近沙发、低头观察并用手触碰毛毯。无需同时让褶皱细节和全身表情都十分清楚。
- **摄影机高度**：可从接近成年人胸部至肩部的高度测试，以能看见沙发坐垫上表面且不被扶手遮挡为准；具体数值待模型确认。
- **道具和手部**：妻子仍持换洗衣服；用空着的一只手完成接触和抚平，不强加放衣服或看衣服的动作。
- **表演节拍**：已经确认异常 → 走近 → 在沙发前短暂停顿并观察 → 手触碰毛毯，略作判断 → 将褶皱抚平 → 手短暂停留后收回 → 看向书房方向。
- **人物心理**：从疑惑到一点不满；停顿必须代表判断或决定去问丈夫，不为制造“演技感”而拖长。
- **镜头运动**：固定，不追随、不推进，不额外加手部特写；若实际空间无法同时覆盖走位与整理，先调整候选构图或报告局限。
- **剪辑点**：妻子收手、转向书房并迈出第一步时，利用运动接入 C08。
- **与 C01 呼应**：同一物品区域，两次整理动作的节奏不同；第一次流畅，第二次略有犹疑。保留可识别的空间锚点，不要求两镜完全同机位。

### C08｜轻跟妻子走向书房，并完整质问

- **摄影机／构图**：从妻子后方偏侧的中景轻微跟随，画面兼顾她的肩背／部分侧面和前方书房入口。
- **运动开始**：从 C07 妻子迈出第一步的动作匹配剪入。摄影机在她已经起步后跟随，行进平稳，不做刻意晃动。
- **动作与终点**：妻子带一点不高兴走到书房门口并停住，摄影机随之停在门外或附近，**不进入书房**。
- **声音**：随着接近书房，游戏和鼠标声逐渐清楚；声音透视需符合真实距离，不用额外紧张音乐。
- **完整台词**：妻子在门口说完——“你刚刚是不是又坐沙发了？”
- **最终切点**：**整句质问结束之后**，才切 C09；不在台词中途切走。
- **备用方案**：若沙发到书房门口距离太短，跟拍缺乏表达价值，则试用固定机位／脚步声桥接；但原先商定的轻跟保留为首选候选。
- **验证要点**：摄影机实际可行走路径，门框遮挡，跟拍尾点与 C09 的轴线关系。

### C09｜书房内侧：丈夫停手、抬头、一愣

- **摄影机／构图**：书房内侧、偏斜的固定中景。优先尝试同框看见鼠标操作手、丈夫上半身及面部；若受书桌和门框遮挡，**面部与抬头错愕优先于鼠标细节**，鼠标声可辅助交代操作停止。
- **时间关系**：妻子的整句质问已在 C08 中说完，C09 切入后丈夫才完成理解与反应，避免两镜重复同一句台词。
- **表演节拍**：丈夫原本在玩游戏 → 操作鼠标的手停止 → 抬头看门口妻子 → 短暂错愕（半秒至一秒为候选） → 温和、略带被冤枉的感觉回答。
- **台词**：“没有啊，我没碰沙发。”
- **表演要求**：真诚意外，不心虚、不夸张地瞪眼；反应先在动作和视线中发生，再说话。
- **镜头理由**：对应 C02 普通对话中他不停鼠标的状态；这次真正被指责，正在进行的行为被打断。
- **摄影机与剪辑**：保持静止；回答结束后略留丈夫等待妻子相信的瞬间，再反打 C10。
- **白模检查**：鼠标手／面部能见度、丈夫眼线与妻子门口脚点、书房内相机空间、对切轴线。

### C10｜妻子不信，沉默离开；本场结束

- **摄影机／构图**：从丈夫一侧朝书房门口反打妻子的固定中景；可保留很少的丈夫肩背作为前景，但不能遮挡妻子。利用真实门框表现两人仍有空间距离。
- **切入**：丈夫第一次否认结束并留下极短反应后切至妻子。
- **台词和反应**：妻子看着丈夫，仍然不信，说：“我刚刚才整理好的。”丈夫可在画外补一句：“我真没坐，我就去收了个衣服。”
- **结束动作**：妻子不再说“算了”；嘴唇轻抿，短暂停留；把目光主动从丈夫身上移开；转身，拿着换洗衣服朝卫生间走去。脚步略干脆，但不甩门、不夸张，也**不再回头看客厅或沙发**。
- **摄影机／场尾**：固定，不跟出去。妻子出画后，门口短暂留空约半秒至一秒作为节奏候选，再切出本场。无悬疑音乐，不必补丈夫的面部特写。
- **镜头理由**：她通过目光撤离与身体离开主动终止争论；双方都未被对方说服，但冲突仍停留在普通夫妻摩擦层面。

## 4. 关键声画与剪辑接口

| 接口 | 需要成立的连续性 | 当前选择 |
|---|---|---|
| C01 → C04／C05 | 不提前展示毛毯变化过程，不证明丈夫碰或没碰沙发 | C04 切在沙发附近关键经过段落之前；衣架声画外交代 |
| C05 → C06 | 妻子视线方向对应沙发，观众此时才看到变化 | 她第二次确认、目光落定后切 |
| C06 → C07 | 人物空间位置和心理状态连续 | 回到她已经确认的状态，直接走近，**不重复惊讶** |
| C07 → C08 | 行走动作连续，不突然跳位 | 她迈第一步时动作匹配切到轻跟 |
| C08 → C09 | 妻子台词完整，丈夫反应不抢在质问结束前 | 完整问完后切丈夫，手停→抬头→错愕→回答 |
| C09 → C10 | 丈夫等待回应与妻子不信形成因果 | 夫第一次否认后略留反应，再切妻子 |
| C10 → 下一场 | 不靠恐怖音效刻意强调第一次异常 | 妻子出画，门框短留空，雨声维持生活感 |

## 5. Blender 三维动画验证要求（下一阶段）

本方案在场面调度上仅完成导演候选设计。**正式机位不能凭文字或单张 AI 图宣布通过**。

1. 读取已批准房屋平面、家具母版与现有 `.blend` 白模；保持同一坐标原点和真实门洞方向。
2. 为人物标注卧室出口、欲转去卫生间的停步点、沙发整理位置、书房门口及丈夫书桌座位；缺失真实尺寸时标“待核”。
3. 为 C01–C10 建立候选摄影机位置、朝向、景别和遮挡清单；特别验证 C05、C07 与 C08–C09 的空间连续性。
4. **先将 C08–C09 制作成真实三维动画**：妻子实际走位、摄影机真实跟随到门口并停下、整句质问结束后切书房内侧、丈夫实际操作鼠标／停手／抬头／错愕／否认。不能仅用静态图轮播冒充动画。
5. 交付可编辑 `.blend`、正常速度可播放 MP4、俯视机位图、真实摄影机视图和遮挡／轴线问题报告。必要时给两种候选构图对比，不擅自挪家具。

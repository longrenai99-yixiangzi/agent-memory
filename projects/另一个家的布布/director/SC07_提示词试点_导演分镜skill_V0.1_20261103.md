【连续性基准】

本场为 A 世界客厅，第九天清晨，雨刚停，晨光从画面右侧的封闭阳台窗斜射进来。空间以“客厅正面场景”（朝沙发）和“客厅反面场景”（朝电视）为准：灰绿色墙前是米白色 L 型沙发，贵妃位在正面场景画面右侧、靠近封闭阳台；沙发前是浅原木茶几；浅色抛光瓷砖地面，无地毯。电视墙在反面场景：电视柜与高柜，旧相框立在电视柜上，白色房门在右侧。

妻子穿浅银灰滚边长袖睡衣和长裤、浅粉色厚底一字拖，棕色低盘发，开场在餐厨方向（正面场景画面左侧之外）。丈夫穿灰绿衬衫、深灰长裤、白鞋，戴细框眼镜，在餐厨方向，晚些入画。薄毯为灰棕色带流苏，搭在贵妃位上，靠阳台端、扶手旁有一道浅褶皱，毯面其余几处凌乱；抱枕略歪；遥控器偏离茶几上的原位。

B 世界客厅与 A 世界沙发区布置完全一致，窗边多一座原木猫爬架；B 世界妻子穿黑色吊带长裙、黑色夹脚拖，同一张脸，棕色低盘发；布布是一只浅奶油色细短卷毛、蓝眼睛、大耳朵的德文卷毛猫，不戴项圈。

P1：全景/35mm F4/时长： 秒/

```
客厅正面场景机位，固定不动。清晨的晨光从画面右侧阳台窗斜射入室内，地砖上有窗格的光影。客厅里没有人。妻子从画面左侧入画，走向沙发贵妃位（画面右侧），在贵妃位前停住，面朝沙发，背对镜头偏左，薄毯的毯面朝向镜头。结束时她站在贵妃位前，其余物件位置不变。无台词。
```

P2：近景·插入/50mm F1.4/时长： 秒/

```
客厅反面场景朝向电视墙，固定不动。晨光照亮电视柜右端的旧相框，木框略有磨损，照片里年轻的妻子抱着布布，照片内容以提供的原照片为准，不重绘。对焦锁定在相框上，镜头不推不拉，画面保持静止，停留的时间比其他镜头更久。无人入画。无台词。
```

P3：中景/35mm F2.8/时长： 秒/

```
客厅正面场景机位，固定。妻子站在贵妃位前，面朝沙发，背对镜头偏左。她先伸手把画面右侧倾斜的抱枕扶正，然后俯身，把茶几上偏离原位的遥控器放回茶几的原位，直起身。结束时抱枕摆正，遥控器在茶几原位，妻子仍站在贵妃位前。无台词。
```

P4：中景/35mm F2.8/时长： 秒/

```
同一机位，固定。妻子的手掌平展，轻轻抚平薄毯上凌乱的地方，从毯面靠近茶几的一侧开始，向靠阳台端移动，在扶手旁那道浅褶皱旁边停下，没有碰它。结束时毯面其余处平整，只剩扶手旁那一道浅褶皱，妻子的手悬在它旁边。无台词。
```

P5：中近景/50mm F2.0/时长： 秒/

```
机位在沙发的另一观察侧，朝阳台和书柜方向，薄毯在画面左下前景，固定不动（以 SC01 C05-A 的摄影机为准）。妻子站在贵妃位旁，侧脸入画，视线落在扶手旁那道浅褶皱上。她一只手掌展开，向褶皱移动，指尖轻轻落在褶皱上，停住，不拖动。结束时指尖停在褶皱上，视线不动。无台词。
```

P6：中近景/50mm F2.0/时长： 秒/

```
同 P5 机位，固定不动。妻子的指尖仍停在扶手旁那道浅褶皱上；她把手向后收回，垂到身侧。褶皱留在原处，毯面没有被抚平。她的视线随手收回而抬起，侧脸朝向画面右侧。结束时手垂在身侧，褶皱保留。无台词。
```

P7：近景/85mm F1.4/时长： 秒/

```
从妻子侧前方拍，固定不动，对焦在她的眼睛上。她的视线先落在薄毯的浅褶皱上，停一拍；然后抬起，望向画面外的电视柜方向，停住；嘴角极轻地上扬一点；眼睑微微下垂；呼吸变慢变深；眼眶微湿但没有眼泪落下。视线始终不看镜头。结束时她的目光停留在画外电视柜方向。无台词。
```

P8：双人中景/35mm F2.8/时长： 秒/

```
客厅正面场景机位，固定。妻子站在贵妃位旁（画面右侧），面朝画面外的窗。丈夫从画面左侧外的餐厨方向走入画面，在她的左侧（画面左侧）停下，与她并肩，两人朝同一个方向。妻子轻声说出下面的台词；她说完后，丈夫没有追问，轻轻握住她的手。结束时两人并肩站着，丈夫握着她的手。
妻子：它在那边，过得挺好的。
```

P9：中近景/50mm F2.0/时长： 秒/

```
固定。妻子转头看向画面右侧的阳台窗外，阳光落在她的脸上，她的手仍被画面左侧外的丈夫握着，手臂入画一侧边缘。她的视线持续看向窗外，不看镜头。结束时她仍看着窗外，阳光落在脸上。无台词。
```

P10：特写·插入/50mm F1.4/时长： 秒/

```
固定，对焦锁定在薄毯上、扶手旁那道浅褶皱。晨光落在褶皱上，毯面其余处平整。镜头静止，停留片刻，无人入画，无手入画。结束时仍是这道褶皱。无台词。
```

P11：中景/35mm F2.8/时长： 秒/

```
B 世界客厅，同样的清晨，晨光从阳台窗斜射入。机位与 P5 相同（沙发另一观察侧朝阳台方向），固定。贵妃位上的薄毯旁，布布蜷成一团睡着，浅奶油色细短卷毛被阳光照亮；窗边深处立着一座原木猫爬架。画面里没有人。结束时布布保持蜷卧。无台词。（B 世界参考图为候选，待批准。）
```

P12：中景/35mm F2.8/时长： 秒/

```
同 P11 机位，固定。B 世界妻子（黑色吊带长裙，黑色夹脚拖）从画面左侧外的餐厨方向走入画面，经过沙发时脚步不停，顺手轻轻摸了摸布布的背。布布闭上眼睛。结束时她的手离开布布，站在沙发旁，布布闭着眼蜷卧。无台词。
```

P13：近景/85mm F1.4/时长： 秒/

```
固定，对焦锁定在布布身上。布布闭着眼，呼吸平稳起伏，细短卷毛随呼吸轻轻起伏，晨光落在毛上。镜头保持静止，画面内容不变，淡出由后期完成。无台词。
```

P14：俯拍广角大全景·站位记录/24mm F5.6/时长：2 秒/

```
固定高位斜俯拍广角大全景，沿用 B 世界客厅真实的沙发、茶几、窗边猫爬架等固定地标。画面记录 P13 结束时的全场状态：布布蜷卧在贵妃位的薄毯旁，闭着眼；B 世界妻子站在沙发旁，朝向沙发，摸过布布之后手垂在身侧；窗边立着原木猫爬架。摄影机、人物与猫保持静止 2 秒，不新增任何动作、走位或台词。无台词。
```

## 试点后的自检（我对照 skill 第十一节做的）

| 项 | 结果 |
|---|---|
| 对白逐字 | P8 一句，“它在那边，过得挺好的。”与剧本一致；其余镜头无台词 |
| 镜头数量与编号 | 13 个剧情镜头 + 1 个站位记录镜头，编号连续；S07-01 室外窗空镜没有场景图，不在本稿 |
| 每镜一个说话人 | P8 只有妻子说话，丈夫只有动作 |
| 动作与结束状态 | 每个 P 都写了结束状态，下一镜从结果承接；P5、P6 把“碰一下再收手”拆成两个状态 |
| 不写心理解释 | 用视线、嘴角、眼睑、呼吸、眼眶写可见变化 |
| 主观镜头 | 本场没有主观镜头 |
| 尚未验证 | 左右方位按 VIEW-03 的朝向推导（餐厨在画面左侧、阳台在画面右侧），未经 Blender 实测；P11–P14 的 B 世界参考图未批准 |

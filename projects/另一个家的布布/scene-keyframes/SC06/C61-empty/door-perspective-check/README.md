## 不能越过的结论边界

1. 这说明按当前批准平面推导的方向，并不证明v03生成相机实际等于C61；若其相机本身错误，只改门不会使整图正确。
2. v03右侧真实门框受玄关柜遮挡，不能把可见窄条当完整门宽；也不能在不知道完整门边的情况下直接宣称哪条现有线是近边。
3. 用户感觉角度反了是需要调查的问题，尚不能将“必须左右反向”写成已核实事实。前几轮凭斜率调整而没有先确定深度，方法不可靠。
4. 本轮只交付方向核对图，**尚未定位照片中的真实消失点、门四角或门洞/柜体深度，不修门、不放人物**。需用户核对方向后再决定校正，并保持既有空间母版不变。

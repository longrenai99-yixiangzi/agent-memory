## 对板上内容逐项核对

### SPACE板

- 平面和北箭头支持：北侧厨房/岛台、西侧电视白柜、东侧靠实体墙沙发、南侧夜窗/窗平台；入户位于北侧偏西。
- 厨房方向标“已更新、选定版”，北后墙为连续墙面/柜体、无横向窗。该视图冰箱在画右。
- 电视墙/两个沙发正面视图标“原图保留”，用于空间和人物眼线；不能因此把各向示意当同机位首尾帧。
- 右下“后续需补充”柜内结构和厨房主观仅为当时示例；柜内当前由已批准A/B2/C2接替，不重新按小图造上下两层。
- 图是视觉空间板，不具准确柜深、门扫掠、手臂可达范围、地面净距的测量证据。

### OVERVIEW板

- 主要事件可读：整理→走柜→移布露盒→反应→取盒→回沙发→丈夫厨房/加入→开盒→照片→相视。
- 中段“回到沙发”“丈夫洗水果”出现编号与COMPLETE板不一致的情况；执行编号用已有全场台账，不增镜、不重命名既有原件。
- 04格局部手/盒画面与当前已批准D2仅人物反应不同，不据此撤回后续批准。
- 09双人入座构图与COMPLETE板示意不完全同一版本，不能挑选其中一张自动作为正式双人首帧。

### COMPLETE板

- 逐格对应：01日常整理；02走向白柜；03取布露盒；04柜内反打；05取出旧盒；05A旧盒特写；06回沙发；07丈夫洗水果；08丈夫看妻子；09到沙发；10膝上开盒；11照片；12相视微笑；13声音转场可选。
- 03“露角”、04“决定取出”的旧文字仅作意图参考。最新B2允许多条布、只露少量盒盖；04只反应、05移篮后取盒，按用户后续确认执行。
- 09示意可见疑似第三位老年人物，不能作为三人故事或生成条件。10开盒、11照片、12相视的人物与手部仍需独立实图审核。
- 05A示意为持盒特写，不等于旧资产编号05A柜内近景。
- “13个镜头、约90—120秒”是板上候选说明：01—12+05A为13核心条目，可选13另计；02已批准拆WALK/OPEN后执行条目增加，不意味着全场已批准14个摄影镜头或硬凑120秒。
- 各格人物身份、服装、盒材质与照片内容只作示意，采用正式身份、衣着、PR01与照片资产，不从缩略图提炼另一张脸或新盒。

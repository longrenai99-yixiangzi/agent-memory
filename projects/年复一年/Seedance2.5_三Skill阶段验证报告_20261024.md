## 三、统一 SC01-P02 文本测试

输入基线：老年妻子已在沙发旁直身起步，沿木茶几外侧可行走通道向画面右侧白色下柜行进，双手空出，柜门始终关闭；本段不下蹲、不拿抹布、不出现旧盒，也不提前进入怀旧情绪。夜景、人物身份、正式服装及白木客厅空间拓扑应保持连续，白柜不可与右侧百叶壁龛混淆。

测试假设为固定平视中远景方案 A、约 5 秒、16:9；**仅为跨 Skill 比较输入，不构成导演批准**。没有附实际参考图或平台素材编号，不得伪造 `@图片`、`@视频` 绑定。

素材职责：

- `SC01-KF-001`：全屋拓扑、同侧摄影机、柜前结束状态。
- P01 约 7.6 秒实际起步帧：人物起步及服装动作连续性，不复制其原近景透视。
- `SC01-CHR-W-001`（必要时 002）：人物面部与年龄。
- `SC01-COST-W-001`：衣装参考，不复制占位脸、背景或站姿。

本轮来源报告**没有进行真实像素审查、通道净距测量、P02-FIRST 视觉验收**。镜头的首尾输入可行性和下一镜 C01 脚位对齐仍需另行核对。

## 五、协同分工建议（待隔离触发证据进一步验证）

1. **Director：** 从统一导演稿提取叙事目的、起止状态、资产职责、硬约束与审批边界。
2. **Shot Design：** 只补充/审查走位、重心、视线、摄影机、节奏和剪辑接口，避免重新设计已批准剧情。
3. **Prompt Skill：** 将审查后的统一镜头稿编译为 Seedance 专用中文提示词，保留唯一参数表和素材绑定表。
4. **H3：** 继续使用单独标准与版本，不直接复制 Seedance 最终提示词。

存在的问题：三个 Skill 的描述范围明显重叠，可能发生自动选择冲突；出现额外相似命名 Skill；Director 参数外置，而 Prompt Skill 倾向参数置于正文前；不同 Skill 的长视频路由与缺省参数不可未经平台核验就作为项目硬约束。

**最小原则：** 本阶段不重装、不移动、不改名任何 Skill，不根据主观观感排名；先把固定职责和测试边界写入项目标准，待有误触发证据再考虑修改描述。

## 六、V0.1 标准校准与 V1.0 发布门槛

本轮已足以支持在 **V0.1 草案**中明确/强化：

- 精确调用名与拟定的 Director → Shot Design → Prompt Skill 分工；
- 一份统一导演真源，Seedance / H3 分别转译；
- 参数表只维护一份，平台/模型默认值不得覆盖用户已定条件；
- 无真实已上传素材编号时禁止编造 `@图片/@视频` 引用；
- 提示词结构检查 ≠ 视频生成/导演验收；
- 文本试例镜位 A、5 秒与画幅仅是测试假设，P02 机位/时长仍待用户确认。

**V1.0 尚不能正式发布**，因为至少缺少：

- [ ] 三个互相隔离的新会话分别独立显式触发，留存调用/读取证据与原始响应。
- [ ] 不点名调用的隐式触发、相邻负例（如只改对白标点）及误触发检查。
- [ ] P02 实际参考素材原图、构图/走位/机位审查，真实输入编号绑定。
- [ ] 用户确认 P02 的机位、时长与剪辑接口。
- [ ] 至少一个 Seedance 真实视频试拍通过剧情、人物、空间、运镜、连续性及剪辑接口关键验收。
- [ ] 关键测试产物与最终结论归档，可供另一智能体复核。

来源会话仅消耗常规文本调用，没有声称使用收费视频生成。本归档不修改媒体、不批准镜头、不代表 V1.0 发布。

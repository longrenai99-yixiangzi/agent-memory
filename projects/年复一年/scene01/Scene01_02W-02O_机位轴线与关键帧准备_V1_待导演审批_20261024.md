## 1. 摄影方向结论与冲突

从 V3.5 平面图的**北向箭头**可确认：

- **北：** 开放式厨房、岛台、入户方向；
- **西：** 电视墙与其白色下柜（故事的目标柜）；
- **东：** 沙发，靠东侧实体墙，不可变为背后开阔空间；
- **南：** 既有夜间窗/窗边区域，不能在厨房北侧另造横向窗。

因此，在 **摄像机位于客厅南侧、向北或略向西北观察** 时：
- 画面**左侧是西侧电视/白柜，右侧是东侧沙发**；
- 妻子从沙发走向白柜，应大体**从画面右向左运动**；
- 中央木茶几处于前景至中景，动线要绕其真实外缘，不能横穿茶几/沙发/岛台。

2026-10-22 P02 导演稿曾记“沙发画左、白柜画右，左→右移动”。这不一定在任何摄影机下都错误，但**不能和上述南侧朝北机位方案同时生效**。必须先确定摄影机哪一侧，再在提示词里锁定屏幕运动方向。不能为了对齐旧示意图而左右镜像整个房间。

V3.5 原“02 走向白柜”多格示意图并不足以证明镜头中的白柜就是**西侧电视墙的低柜**；其近窗独立柜体、门型与低柜高度/透视关系，需要用正式场景母版重做比对。图像只提供人物接近目标柜的镜头意图，不能直接当作 02-WALK 或 02-OPEN 的可用首尾帧。

## 2. 方案 A / B（均在运动轴线南侧）

| | A：南侧稍偏东，朝北偏西的固定中远景 | B：东南侧更斜的固定宽景 |
|---|---|---|
| **机位逻辑** | 位于室内南部可站立区域，镜头向北/西北；东沙发应在画面右侧，西柜在左侧 | 略偏东南斜拍西北，仍保持在妻子东西向行动线南侧，不反越行动轴线 |
| **信息目标** | 一镜建立沙发—茶几—白柜的真实连续空间及人物走位 | 加强白柜正面可见性，可能让前景茶几更挤/走位更斜 |
| **人物运动** | 大体从画右至画左，绕桌不跨桌，最终停于西侧白柜面前 | 同属从东往西，画面方向不能因斜角完全反转 |
| **摄影** | 固定中远景；可见头、脚、柜前停位；不需要跟拍 | 固定中远景，必要时更偏向柜体但不牺牲起步位置 |
| **潜在问题** | 西侧低柜可能被植物/电视墙侧柜/沙发扶手遮挡，需要实图验证 | 起步人物与柜体可能被透视压重叠，实际室内角落净距未知 |
| **推荐** | **先做 A 的单张机位验证图**，优先检验空间，不等于批准 | 仅当 A 不能同时看见真实通道和目标柜时再试 B |

## 3. 镜头接口与三张关键状态图

### 02-WALK-FIRST｜新机位建立与 P01 接入

**叙事任务：** 用宽景交代妻子从沙发一侧自然开始向白柜走，柜门仍关；观众能理解为什么要转向另一处整理。

**机位：** C1 固定中远景（方案 A），自然室内高度；人物起点在画面右侧沙发外侧，白色目标下柜真实存在于西侧电视墙（画面左侧）；中央茶几位于真实地毯位置，预留实体通行区域。

**人物：** 已离开 P01 弯身整理姿态，双手空着、开始起步；脸上没有旧盒相关的回忆/惊讶。正式灰白低盘发、奶油针织开衫、灰绿低对比连衣裙、低跟鞋一致。

**摄影/空间：** 16:9 横向写实电影静帧候选。保持暖室内光与窗外冷夜分离；南侧窗在摄像机后方或侧后方，不必在向北构图时凭空出现在厨房后墙。

**不能出现：** 高柜替代白色下柜；柜门提前打开；人物已走到柜前；妻子拿盒/拿抹布；镜像房间、第二张窗、厨房后横窗、沙发背后开阔空间。

### 02-WALK-LAST｜柜前停稳的剪辑点

- 相同 C1 机位与场景；妻子已沿经过核验的桌外通道抵达目标白柜前，双脚真实着地、身体转向西侧柜面，**未触门把，柜门关闭**。
- 手、脚、转身方向与 02-OPEN-FIRST 能匹配；不要求两镜首尾帧像素级叠合（跨机位用硬切），但人物空间状态不能改变。
- 人物与白柜可操作间距必须支持自然伸手开门和随后蹲稳；不得把双脚压进柜脚或地毯纹理，避免“人物半穿柜体”。
- 此尾帧需要在 02-WALK 动作与机位核对之后正式生图并验收；**不能直接把 02-OPEN 的门开状态当尾帧**。

### 02-OPEN-FIRST / LAST｜近景开门、完全下蹲

**起点：** 在 C2 机位重新拍摄同一空间状态——同一白柜、门关、妻子柜前站稳、手尚未碰门。

**镜头中段：** 伸手握目标柜门把→门沿**真实已存在铰链**打开→调脚位→完整下蹲。

**末态：** 柜门开，妻子完全蹲稳；下层目标格中的收纳物仍处于 A“旧盒完全不可见”的初始遮挡状态，未开始拿掉浅色毛巾；上层既有篮/罐/碟不动。

**机位：** C2 与 C1 保持同一行动线侧别，允许从宽景切成柜前中景/中全景；相机不能位于柜门实际扫过区域，也不能低得导致站姿或蹲姿丢失。

**切镜位置：**
- P01→02-WALK：利用人物离开沙发的真实身体动量做有动机硬切；
- 02-WALK→02-OPEN：以“柜前站稳，手尚未触柜门”作为状态切点；无需人物步伐完全像素连续；
- 02-OPEN→03：在**柜门已开且人物完全蹲稳**之后切到柜内更近景；不能在下蹲途中重置姿态或提前露旧盒。

### 这张图的通过标准（六项）

1. **房屋朝向正确：** 西侧电视/白柜画左、东侧沙发画右、北厨房在后，南窗不被搬到厨房。
2. **白柜身份正确：** 同一个电视墙低柜，不是独立高柜或右侧百叶柜。
3. **路径存在且看得见：** 可从妻子当前站位通过茶几外侧到柜前，人物不必穿过家具或摄像机。
4. **起点正确：** 妻子仍近沙发，已离开整理动作，双手空着，不提前走到柜门。
5. **身体与光影连续：** 已批准人物服装、比例、背景受光方向匹配；没有夸张皮肤平滑和橙染。
6. **切点潜力：** 该固定摄影位能在 02-WALK 同一构图内保留人物真实到达白柜的画面空间，不在左边出画才到柜前。

# 图片审查交接

用于 Codex、ChatGPT 与用户之间交接生成图片的审查任务。

## 最小流程

1. Codex 复制 `tasks/TEMPLATE.json`，生成唯一任务文件，例如 `tasks/IMG-20261020-001.json`，填写图片路径、所属场次、镜头编号、用途和待核对问题。
2. 用户把图片放入任务记录的 `image_path` 指定目录，并确认路径可读。
3. Codex 将任务文件与图片路径提交到共享记忆仓库。
4. ChatGPT 读取图片和任务文件，在 `review.result` 写入逐项结论、证据和待确认项。
5. Codex 根据审查结果更新 `status`，涉及导演创作判断的修改保持 `needs_user_confirmation`，由 ChatGPT 与用户共同确认。

## 状态

`待提交` → `待图片` → `待审查` → `待用户确认` → `已通过` / `需修改` / `已取消`

审查结论只能基于实际可读取的图片；路径不可读时标记 `待图片`，不凭任务文字推断图片效果。

## 路径约定

- `image_path` 使用仓库相对路径，或使用双方都能访问的绝对路径。
- 图片文件与任务文件分开保存；任务文件不内嵌图片二进制数据。
- 不上传隐私、涉密原图、密钥或访问令牌。
